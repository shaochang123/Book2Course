# 智讲 Agent（Book2Course）

**语言 / Language：** [简体中文](README.md) | [English](README.en.md)

将有使用权的教材、讲义和知识型 PDF 转成可溯源的中文教学视频与 PPTX 课件。支持文字提取、本机 OCR、课程规划、讲稿、SVG 图示、配音及视频合成。网页可查看讲稿、PDF 页码、原文摘录和知识关系，并下载 MP4、PPTX 与场景数据。

**真实 AI 模式**使用本机 Ollama 或兼容服务；**确定性演示模式**无需模型和密钥，明确标注为规则生成。来源匹配、模型审稿和计算检查都有各自的范围，教学内容仍需人工复核。

## 快速开始（Windows）

在项目根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[test]"
.\.venv\Scripts\python -m uvicorn zhijiang.main:app --host 127.0.0.1 --port 8765
```

打开 [http://127.0.0.1:8765/](http://127.0.0.1:8765/)，选择[原创示例 PDF](examples/binary_search_original.pdf)，确认使用权，使用演示模式和 Windows 系统语音体验。完成后查看讲稿、来源、视频与课件。**在启动服务的终端按 `Ctrl+C` 关闭服务**；关闭浏览器不会停止服务。

Python 要求 3.11+，已在 Python 3.13 上验证。系统配音需要 Windows 中文语音；其他环境可配置兼容语音 API。`imageio-ffmpeg` 提供 FFmpeg，无需安装系统 FFmpeg。

## 模型与动画配置

首次配置可复制模板；已有 `.env.local` 时直接编辑，保留现有配置：

```powershell
Copy-Item .env.local.example .env.local
ollama list
```

将 `ZHIJIANG_LLM_MODEL` 改为已安装的模型名，启动 Ollama，再重启 Web 服务。数学对象模式需要支持图像输入的模型；本机使用 `qwen3.5:9b`，建议开启 `ZHIJIANG_OLLAMA_SEMANTIC_THINKING=true`。`.env.local`、模型权重、上传资料和生成物均被 Git 忽略。网页也可配置单次任务；外部服务须确认发送文本、数学模式的教材页图像或讲稿，任务密钥仅在进程内存中保留。

可选 `ZHIJIANG_OLLAMA_NUM_GPU` 控制 Ollama 的 GPU 层数，留空使用自动分配。本机 8GB 显存同时运行桌面应用时使用 `24` 保留余量；其他机器需按实际资源调整。数学构造调用使用 16K 上下文，推理速度与显存、内存及模型有关。

`ZHIJIANG_OLLAMA_THINKING_LEVEL` 可填写服务实际支持的推理档位，留空沿用服务默认值；不支持该档位会明确报错。只有布尔推理开关的模型仍使用 `ZHIJIANG_OLLAMA_SEMANTIC_THINKING`。不同模型、档位与硬件的结果不能直接当作模型能力排名。

```powershell
.\.venv\Scripts\python -m pip install -e ".[math-animation]"
```

| 动画方式 | 当前行为 |
| --- | --- |
| `auto` | AI 默认；按来源选择关系、流程、比较、原页或几何场景。环境未就绪时使用基础图示并说明原因。 |
| `visual` | 通用场景；未通过来源或执行检查时明确失败。 |
| `geometry` | 通用二维数学对象推演；需要 TeX，失败时明确报错，不回退到关系图或原页高亮。 |
| `math` | 二维线性变换专用推演；需要相应原文和 TeX。 |
| `basic` | 基础要点图示；确定性演示使用此路径。 |

原生关系图与原页讲解无需 TeX；可计算几何和专用数学推演需要 `latex`、`dvisvgm`。系统语音、Kokoro、外部 API 与续跑见[生成配置与恢复](docs/生成配置与恢复.md)，图示和 skills 见[教学图示与动画](docs/教学图示与动画.md)。

## 自然讲解配音（可选）

可在独立 `.venv-tts` 中运行 **Qwen3-TTS 0.6B Base**，以本机参考语音匹配讲解声线。网站提供默认声线试听，AI 配音用于视频和 PPT。声音提示、权重和 `.env.local` 均被 Git 忽略；参考音频与讲稿留在本机。安装、启动与 CPU/GPU 配置见[本机自然讲解配音](docs/自然讲解配音.md)。

启动语音服务使用 `.\scripts\start_voice_service.ps1`，在其终端按 `Ctrl+C` 关闭。设置 `ZHIJIANG_DEFAULT_VOICE_MODE=ai` 后，新网页默认使用已配置的 AI 声线；旧任务和未指定配音模式的 API 保留原行为。音色与自然程度需要试听判断。

## PPT 模板与课程导演

网页可选择 **深色演示、纸上讲解、学术课堂、杂志叙事**，并查看版式示意。新模板提供问题引入、课程路线、图文分栏、证据边栏、图下注释与回顾页。真实 AI 根据内容选择模板允许的版式、已有短句和是否增加动画页；演示模式明确使用规则排版。复杂数学图保持大幅画面与已有连续动画。

新生成任务的 PPT 与完整 MP4 共用模板、正文布局和配图；数学场景以保持宽高比的窗口播放原有连续演示。标题约 36–44 pt，正文至少 24 pt，长文字拆页；来源页码、模式与技术标签保留在备注和网页。旧任务未设置 `ppt_template` 时沿用 `classic`，网页新任务默认 `paper`。尚未支持上传任意 PPTX 母版；详见[课程导演与 PPT 模板](docs/课程导演与PPT模板.md)。

关键句尽量整句展示，额外讲稿片段只有在空间足够时才上屏；完整讲稿保留在备注，避免为一段残句增加空续页。

真实 AI 的普通课件在排版前检查短句是否逐字来自讲稿；未绑定的短句由模型改为选择现有完整句子编号，程序填入原句，避免再次改写时颠倒条件、否定或关系方向。数学连续场景保留自己的已核验表达。此约束不证明讲稿本身正确。

## 可检索教学素材

内置 **100 个原创线条符号和 9 个有出处的 CC0 手绘插画**，覆盖生活农业、计算机、数学、物理工程、化学、生物、教育、医疗、金融、法律、汽车交通和历史。手绘书本保留彩铅纹理，西瓜和灯泡保留自由笔触；外部原作的作者、来源与许可逐项列在素材目录中。网页默认开启“自动检索插画与符号”，真实模型从最多 8 个本地候选中选择每页最多一张主要配图、两枚辅助符号；同一对象优先选择插画，演示模式使用确定性匹配。配图绑定对应的实例或要点，合计占普通页面不到 8% 的面积，知识重点与教学演示占主体。知识与数学关系仍来自教材和独立演示。

检索关键词与对象别名分开：相关学科词不能自动作为图片名称，例如肺部图不会被标为肺泡；英文别名按词边界匹配。一个对象只提供一个优先配图候选。未找到合适素材时保留知识画面并记录缺口，当前九个手绘条目尚未覆盖所有领域。

素材目录是 [zhijiang/assets/visuals](zhijiang/assets/visuals/README.md)，每一级目录的 README 描述子目录及素材。支持新增 SVG 和透明 PNG，使用随主依赖安装的 `resvg_py==0.5.0` 生成透明兼容图。索引、预览与缓存存于忽略的 `data/`：

```powershell
.\.venv\Scripts\python scripts/index_visual_assets.py --check --rebuild --contact-sheet
```

创建及重试 API 支持 `use_illustrations`，默认开启，重试未填写时保留原选项。目录描述或素材变化会使配图规划缓存失效。添加素材与验收流程见[素材库与共享画面](docs/素材库与共享画面.md)。

## 流程

[![从 PDF 到视频与课件](docs/workflow.zh.svg)](docs/workflow.zh.svg)

定性图示先独立理解来源，再提取命题，按主语、谓词、宾语及条件构建知识关系。模型选择来源编号，程序绑定引文并共享 SVG/动画布局。参数化几何通过受限表达式与数值检查执行，不执行模型代码。详见[架构与接口](docs/架构与接口.md)。

定性场景先按标题检索输入中的当前页及相邻页，复核必讲范围，再绑定事实和口播；不再只读短引文前后三句话。PDF 行内斜体的完整外文示例由程序保留，原页注释提供按步骤切换的局部放大。归因、实测与剩余问题见[Agent 与模型能力诊断](docs/agent-model-capability-2026-10.md)。

数学对象模式先对照教材原页图像恢复公式和图形，再分别生成教学设计、数学构造图和讲解操作。通用构造包括点、线、函数、参数曲线、中点、垂足、刚体变换、等面积分割、隐式距离轨迹、逆函数与有限展开；由程序计算依赖坐标、导数和系数，不按教材标题选择预制分镜。SVG 和视频采用等单位坐标缩放。

数学构造按依赖顺序编译；派生量在每个运动帧重新计算，静止讲解保留已核验状态。关系检查直接测量实际对象的距离、角度、面积、函数值和导数，拒绝只校验参数恒等式；镜头范围覆盖运动采样，检查可见点与标签锚点。计算结果与配音、SVG、视频共享，舍入值标为近似值。结构、来源与数值失败会进入明确的修复或失败状态，不以模型审稿代替数学检查；这些有限检查仍不能保证所有知识正确。

坐标测量保留正负号，距离与非负夹角分别计算；可使用有向角。旋转后从实际顶点化简面积和长度，保持渲染数据检查。全程关系与指定步骤的终点关系分开验证；镜头按可见有限对象确定等单位范围，远端函数尾部裁出窗口，避免压缩主体。网页可分别填写同一 API 上的“数学规划模型”和“独立数学复核模型”：生成模型读取原页并审核画面，规划模型生成构造与操作，复核模型检查来源与文字；留空则使用生成模型。独立复核应选与规划不同的模型。角色与实际调用分别记录；复核不等于正确性保证。Ollama 云模型即使使用本机地址也需要发送许可，详情见[配置参考](docs/生成配置与恢复.md#通用数学对象模式)。

数学审稿直接对照教材原图与每步 SVG，先记录来源、几何、连续操作的观察再判定批准。相邻线段可按共同端点测量顶点内角；有向角弧可保留完整扫角，并核验实际弧端点。复杂计算表达式拆为受限的派生节点，不放宽 AST 限额。数值口播仅修复出错句，保留已核验对象和操作；运动帧持续检查，静止讲解保持已核验终态。

刚体变换的原图与副本共享对象身份。前后比较的原图需设为 `reference=true`，画面会淡化并标为“参照”；移动同一对象时隐藏原图。角弧、圆和函数曲线也可刚体变换，旋转后的函数按参数曲线绘制。

原页识别后先独立列出必讲条件、结论和已解核心算例，再规划画面；候选完成后逐项核对实际口播、操作取值和渲染几何。参数曲线上的点可用于测量角弧首尾的实际拼接。数学课按内容安排 3–10 步，简短完整的定性口播无需补字。没有完成标记的模型响应不能作为结果，服务中断至多重试两次。当前修复与教材联合验收记录见[数学修复报告](docs/math-repair-acceptance-2026-10.md)。

来源主语绑定实际对象类型、顶点数及测量依赖，拒绝用无关占位图形替代教材对象；概念照片与装饰插图允许用等价的正确数学示意说明。`align` 按两组真实锚点与方向计算连续刚体对齐，不猜旋转角，不改变长度和面积；角度和、角差标注弧度。持续的语义构造错误会触发有限次数的设计修订，原稿与拒绝原因均保留。

来源主语可明确记录同类对象的数量，绑定时逐个核对类型、可见性和测量依赖，拒绝重复或无关对象。不同类型的并列主语分别保留；已给出的带数量和对应标注的图解方案也按核心算例检查。构造清单中的非有限初态在审稿前拒绝，不能让隐藏辅助对象从无穷远开始。

来源清单先对照原页图像生成，再独立核对翻译、条件和算例；不通过时先修复来源含义。构造完成后，工具返回实际坐标、面积、长度与角度，并检查现有对象和自由度能否表达必讲内容。通用交点工具支持两条直线/射线/线段或两个圆；线与射线按实际窗口延伸，曲线上动点须处于真实绘图区间。完整行为 JSON 的个别字段无效时仅修复对应字段，其他已验证字段保留；损坏 JSON 不按局部正文接受，最终仍须通过完整契约及数学、来源、SVG 和运动检查。

构造修复支持受限的新增、替换和删除补丁，保留未修改的正确对象，并按真实依赖排序。连续两次操作修复失败会返回构造层，即使两次错误措辞不同。构造草稿最多 32 项，分割后核心对象仍最多 48 项，含点名的渲染契约仍最多 64 项。补丁不能绕过来源和实际动画检查。


来源覆盖与构造可表达性按每批两项复核，汇总保留全部要求和拒绝项。已核对的中文来源清单由程序逐字绑定到教材说明卡和配音：定义及条件先讲，算例对应实际演示步骤。说明卡不算数学证明，动态数值仍来自实际对象测量，自由口播继续受数字校验约束。说明卡播放结束后才开始该步数学运动；讲稿保留对应来源说明。逐组验收同时查看来源卡与数学运动帧。

具体几何图解算例还会独立提取来源对象身份图，保留部分、整体、位置和编号归属。模型将实体绑定到真实对象；程序核对类型、相对位置与有限多边形的顶点包含关系，并为来源身份分组及其变换副本分配一致颜色。未参与讲解的静态辅助点隐藏；明确平移方向须与实际采样坐标一致。同色共线的线段、射线或直线完全遮蔽时会要求隔离显示或修正表达。以上为受限结构和运动检查，仍须人工核查来源与实际成片。

## 当前边界

- 单机顺序队列，一份 PDF 生成一节课。上传上限 200 MB，无固定页数或目标时长上限；长教材耗时和产物大小会增加。
- OCR 不保证复杂公式、表格和版面恢复准确；没有人工公式确认界面。
- 数学对象模式读取混合页中的原页图像和公式，识别结果及模型复核仍可能出错；须对照原页核查。表达能力限于受限二维构造和唯一实函数分支，模型规划、模糊原页或不支持的数学操作会明确失败。
- 一个定性场景使用一个来源页，可重新选取输入中的相邻页；需跨页联合解释或缺少标题所需依据时明确失败。范围复核和模型审稿仍可能误判，不能当作事实正确性保证。
- 网页可查看课程和来源，尚未提供项目列表、知识点选择编辑、讲稿编辑或人工审核发布流程。
- PPTX 标题、来源标签与备注可编辑；SVG 路径不是独立的 PowerPoint 形状。通用/专用动画有配音，基础内嵌动画静音，完整视频有配音。
- 受限二维场景与来源关系追踪已接入；复杂三维机制、跨章推理、事实证明、独立 SRT/VTT 字幕与课程 ZIP 导出尚未实现。
