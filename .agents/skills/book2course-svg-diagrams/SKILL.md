# 教学 SVG 图示

从已确认的逐页大纲、讲稿和来源证据提取节点与关系，再选择图形。流程图用起止、处理、判断等规范语义；只有真实分支才使用判断菱形，并在出边标注条件。概念关系图要说明箭头含义，公式图要保持符号和推导顺序。

先辨别要讲解的是过程、因果或依赖、比较、定量变化还是实体结构。每个节点和每条关系须有资料依据；中文对象名与连线的主语、完整谓词和宾语绑定独立原文事实，保留否定与条件，不自由编写关系标签；比较图不强行加入因果箭头，结构图不伪造运动。比较和原页标注可没有连线；独立事实不应为了图形连通而虚构关联。原文事实与原创教学类比分开记录和标注。网页的 `teaching_design.py` 可规划抽象节点与关系，`teaching_layout.py` 为 SVG 和动画共享布局。对于无法忠实重绘的复杂插图，可保留本地 PDF 原图/页面，并在独立 SVG 中内嵌提取的 PNG；标明出处与原图身份，不把它称为原创矢量图。

- 使用有 `viewBox` 的独立 SVG，优先 16:9 画布和适合投影的字号、对比度与安全边距。用基础矢量形状、文字和可编辑连线；避免位图化、外部字体/图片、脚本、`foreignObject` 和会降低 PowerPoint 兼容性的复杂滤镜。
- 节点文案简短，但不能省掉条件、单位或关键步骤。连线避免穿过节点和标签；分支应能从起点顺畅追到结论。必要时拆为连续两页，不把密集图强塞一页。
- 对从 PDF 提取的原文、公式和页码保持忠实；OCR 不确定部分先在交付说明中列出，不以图形美化掩盖事实疑问。将任何不可信文本写入 SVG 前做好 XML 转义。
- 提供 `<title>` 和 `<desc>`，让图的用途及逻辑可以被辅助技术识别。必要的来源页码放在图下方或讲者备注中，不遮挡主要内容。
- PNG 兼容图使用 SVG 的实际宽高，验证完整画布和底部字幕；不能用固定高度裁掉 16:9 图示的来源或讲解。原文明确提供的教学示例优先复用，并在备注保留同一事实与出处。

交付 `.svg` 源文件，并用 XML 解析器验证文件。再渲染预览，检查全幅和缩小后文字、箭头、顺序及边距；若需嵌入 PPTX，还要检查实际幻灯片中的显示效果。
