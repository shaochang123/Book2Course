# 讲解型动画

用连续的视觉变化解释数学和各学科的教学过程。可以借鉴 3Blue1Brown 的教学表达方法；动画、配色、图形和素材针对本课程原创。网页通过 `animation_mode=auto|visual|math|basic` 接入通用参数化场景与二维线性变换专用推演，输出有配音的内嵌 PPTX 动画及同素材教学视频。此技能用于设计、核查与扩展场景；技能文件本身不会被网页作为运行时代码调用。

1. 从已确认的大纲、逐页讲稿和来源摘录确定一个要解释的主问题。写出“初始状态 → 每次变换及其原因 → 结论”的分镜；为每个关键画面列出可见对象、口播句、出现或消失的时点、PDF 来源页码。遇到 OCR 或公式疑点，先标记核查。
   先按教学内容选择表达：可计算变量用几何推演，阶段与信息流用过程图，概念依赖用关系图，方法与条件用比较图，实体外观或复杂结构用原文插图讲解。每条关系写出原文依据。独立事实可采用没有连线的比较图或原页标注，不能为连接所有对象而编造关系。不能因为渲染器能移动点，就把所有输入转换成坐标运动；图示动效应追踪有意义的关系和比较过程。
2. 选择能体现数学或概念关系的变化，例如映射、对齐、拆分、强调不变量、逐项代入和前后对比。移动对象时维持同一符号或颜色的含义；不要用视觉上的连续性暗示未经证明的等价关系。
3. 优先使用可重复编辑的矢量对象。安装 `.[math-animation]` 使用 Manim Community Cairo、SymPy、PyMuPDF 与 Jieba；中文用 `Text`，公式用 `MathTex`，需要 PATH 中的 `latex`、`dvisvgm` 和 `standalone` 宏包。已有 TeX Live 时先检查，不重复安装。auto 环境未就绪时明确说明基础回退，math/visual 模式明确报错。
4. 依据实际口播或配音时长安排变化、停顿和留白，让关键状态在解释期间保持可见。画面保持投影可读的字号、对比度和安全边距；同屏只保留理解当前推理必需的对象。
5. 先低质量预览并修正内容、遮挡、时间线和文字，再输出目标质量。逐帧检查关键公式与转场，完整播放核对配音同步。交付场景源文件、成片，以及可用于 PPT 的封面帧或静态摘要图；只有实际验证过的格式才标为可交付。

## 当前执行器约定

- 整本扫描教材先查看页级 OCR 与知识批次进度，再判断是否停滞；`parsed-pages` 和 `knowledge-batches` 保存已完成工作，重试复用已核验结果。CPU 模型调用显示耗时与已收到字符数，部分响应不是完成结果。设计前核对中文换行、分数与图文读取顺序；缺失的比例和上下标不能按常识猜补。知识摘要仅保留有来源的数值，原创算例另作为带条件、标记和计算核验的场景数据。判断题选项属于待判断命题，保留题目语境，不直接作为定理。
  知识批次的数值错误按条目修正，保留其余通过条目及出错主题，不整批重选或删掉主题来通过检查。`.draft.json` 是可续修的未批准草稿；完成来源与数值检查后才写入正式批次缓存。核对错误条目、缺失来源值和实际修正记录，不能将批次重试当作内容验收。
  数字集合相同不能证明比例或公式正确；知识摘要的定量分句须逐字保留摘录，计算示例交由场景核验。检查中文分数改写，区分泛指词与确切数量、来源名称与测量断言。不能将阿拉伯数字改成中文来绕过数值检查，也不能因检测中文数词而拒绝正常概念定义。
  定性改写持续失败时，模型仅选择当前来源的可读说明句编号，程序逐字填入；候选排除具体数量与分数，不允许跨知识点选句。短摘录不足时可选择同一原页的原文片段编号，程序核对连续文字并更新该出错条目的引用，再编写定性说明；不得跨页猜补，数字串不得直接变成公式。记录 `literal_source_clause` 与 `literal_same_page_quote` 修复及其原句，旧缓存也须核对同页引用。没有可用候选时报告来源问题，区分可读概念与尚需原图核对的定量关系。

- `zhijiang/teaching_design.py`：网页先生成与学科名称无关的教学表达设计，先在不接触候选分镜或用户风格的调用中独立理解完整来源句子，再规划对象关系与逐步口播。中文节点名从独立事实选择，连线也通过 `source_fact_id` 绑定同一事实的主语、完整谓词和宾语，不让模型另写连线标签；复杂从句改用比较或原页标注。口播通过 `source_fact_id` 选择独立来源事实；程序将当前事实与对应的图形焦点、连线绑定，类比通过独立 `example` 字段选择同一事实，程序填入 `source_statement`，不让模型重新改写事实。模型选择来源编号及原文术语，程序填入逐字摘录、检查关系两端依据；唯一可确定的编号误选可以修正并记录。核对完整来源页，保留表达选择依据与所有拒绝原因。`teaching_renderer.py` 连续追踪关系、保留对象身份并同步口播；原文页面从本地 PDF 提取，模型不能提供文件路径。几何候选失败时重新选择有来源依据的表达，不能随便移动对象通过检查。

- 模型控制读取服务返回的实际能力，不按模型名称推断推理开关。CPU 上可使用非推理版进行结构化规划；换模型的验证必须记录，不能宣称原模型已通过。知识点提取保留定义与条件的上下文，不能把表格列名当成概念；语义错误须在生成之前修正。新原文的术语候选由真实文字偏移提取，不增加针对单篇资料的词表或分镜。

- 请求生活例子时，比较或原页讲解优先复用原文明确给出的示例，将示例事实加入讲解和画面焦点，避免另编技术行为。独立事实应为完整中文句子，保留科学名称；英文照抄或截断的旧理解草稿须重新生成。来源示例策略在缓存复用时重新检查，不能保留旧稿中已发现的问题。

- 逐项审查的原文含义允许保留简短对象名称，不能为了固定句长补充新断言；支持判断和理由仍须逐项完成。模型格式失败时查看任务目录的 `model-format-errors.json`，保留实际失败证据；不要删改损坏的正文片段来绕过来源或审稿检查。

- 原页或比较讲解不能把有明确“初始—随后”顺序的相邻操作压成起点与结果；保留对应的来源事实和顺序。`preserve_source_sequence` 根据实际摘录的过程词检查，不用学科专用步骤表。仍须人工核对整个过程是否遗漏关键环节，局部语言检查不证明全章覆盖。

- `preserve_topic_focus` 将当前标题中最具体的来源词语绑定必讲事实，避免用同页的相邻背景取代主题。词语由独立事实提取，按长度和当前事实中的频率区分具体与通用名称，不使用学科词表。核对同义表达、核心概念和整体覆盖，不能仅凭词语相同认定已经讲清。

- `zhijiang/visual_planning.py` 与 `visual_renderer.py`：学科名称不限；模型生成稳定对象、受限表达式和参数步骤，不生成代码。采用曲线、粒子、图形及关系表达连续过程，拒绝只有要点淡入的分镜。公式数值与实际几何同步更新。`visual_media.py` 按真实语音时长合成素材；`verify_teaching_artifacts.py` 验证产物。详见 [通用场景架构](../../../docs/scene-graph.md)。
- 几何分镜每片段 3–5 步；定性图示按内容选择 1–5 步，不为了凑条数增加推论；每步原文事实 `source_statement` 为 12–120 字符，整个片段最多补充一个 12–80 字符、以句号结束的完整 `analogy`；两者分开保存，实际口播明确标出类比。类比不必出现在原文中，但不能改变事实、加入技术机制或保证。禁止公式转义串，几何数值由已核验参数与 calculations 生成口播。逐项审稿须覆盖每个对象、关系和每步事实/类比，记录原文含义、支持判断及理由；不能用一个整体通过标志取代条目核对。通过审稿的分镜可以缓存，重试时重新核查实际来源与执行契约。不要仅凭模型审稿通过认定讲解正确：检查术语翻译、信息流与因果区别、被说成移动的对象是否真的移动、参照对象是否保持、各步是否推进推理。人工提供详细教学指引时，在验证报告中明确记录，不能当成无引导的模型规划能力证明。
- 实际几何记录正确也可能存在 Cairo 图形族缓存残影。替换子图形时须从当前容器刷新图形族，不能复用动画开始时展开的旧列表；检查真实中间帧中的旧位置，不能把重复残留的点或线当作同一对象的正常移动。像素检查仅覆盖颜色可区分的运动点，其余原语仍需检查实际画面。
- 需要专门领域检查时使用已安装的 `book2course.visual_checks` 或 `book2course.visual_validators` 入口，服务器与渲染子进程加载相同实现。完整领域规则能读取 `domain_data` 和场景对象；模型不能定义 Python 检查器。普通新专题可直接使用通用原语，复杂机制再增加专用执行器。

- `zhijiang/math_planning.py`：模型选择参数和教学问题，生成结构化 `math_scene`；固定操作顺序覆盖线性、基向量、平面变换、投影、复合五类场景。先拒绝错误的计算声明，再将事实口播绑定到参数化核验说明，保留模型草稿。不能仅凭正确的 claims 数组认定自由口播正确。
- `zhijiang/math_renderer.py`：只执行程序内置操作，不运行模型生成代码。对象跨步骤保持颜色和身份；旋转采用角度插值，不能用端点直线插值冒充旋转。投影端点沿法线移动；一般矩阵形变只表示初态到终态的过渡。公式在对应操作时变化，中间状态保留到下一句实际配音开始。
- `zhijiang/math_media.py`：逐句配音生成时间线，输出 1280×720、30 fps、有声音的 MP4，保存实际渲染几何检查。SVG 与 PNG 摘要使用相同计算数据，PPTX 按 16:9 嵌入相同 MP4。用 `scripts/verify_math_artifacts.py` 核查完整产物。
- 新参数必须重新计算、核验、配音和渲染；不能只替换矩阵标签。原创数值例子和面积解释标为教学示例，原理引文保留真实页码。通用场景面向各学科的二维表达；复杂三维或真实机制需要专门的数据契约、计算关系与动作验收。
- 报告分开列出计算核验、引文位置与含义核对、视觉检查、完整视频试听、PowerPoint 放映测试。抽帧或 OOXML 检查不能冒充完整播放或实际 PowerPoint 点击验收。
- 扩展微积分、概率论、物理、化学或生物时，先确定领域对象与可验证关系，例如导数的极限过程、概率归一化、物理量纲与守恒、化学计量和键结构。生物示意明确简化条件及来源；不能把画面流畅或基础图示当成领域事实已被证明。新专题通过计算、来源和连续过程验收后再列为自动推演支持范围。

需要 Manim 的安装和渲染参数时查看 [Manim Community 官方文档](https://docs.manim.community/en/stable/)。
