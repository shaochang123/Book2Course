# 讲解型动画

用连续的视觉变化解释一个知识点，而不是为静态文字添加装饰效果。可以借鉴 3Blue1Brown 的教学表达方法；动画、配色、图形和素材应针对本课程原创。网页会为每个讲解片段自动生成基础 SVG 图示和嵌入 PPTX 的讲解动画；此技能用于进一步设计或替换复杂场景。技能产物不会因为技能文件存在就自动覆盖网页生成的素材，接入时应检查 `zhijiang/presentation.py` 的实际格式与流程。

1. 从已确认的大纲、逐页讲稿和来源摘录确定一个要解释的主问题。写出“初始状态 → 每次变换及其原因 → 结论”的分镜；为每个关键画面列出可见对象、口播句、出现或消失的时点、PDF 来源页码。遇到 OCR 或公式疑点，先标记核查。
2. 选择能体现数学或概念关系的变化，例如映射、对齐、拆分、强调不变量、逐项代入和前后对比。移动对象时维持同一符号或颜色的含义；不要用视觉上的连续性暗示未经证明的等价关系。
3. 优先使用可重复编辑的矢量对象。可采用 Manim Community 制作场景和动画；中文正文可用 `Text`，排版数学公式可用 `MathTex`（需相应 LaTeX 环境），已有 SVG 可按需要作为矢量对象导入。若当前环境没有该工具，先交付完整分镜与可制作的矢量素材，再按任务范围安装或选择可用渲染器。
4. 依据实际口播或配音时长安排变化、停顿和留白，让关键状态在解释期间保持可见。画面保持投影可读的字号、对比度和安全边距；同屏只保留理解当前推理必需的对象。
5. 先低质量预览并修正内容、遮挡、时间线和文字，再输出目标质量。逐帧检查关键公式与转场，完整播放核对配音同步。交付场景源文件、成片，以及可用于 PPT 的封面帧或静态摘要图；只有实际验证过的格式才标为可交付。

需要 Manim 的安装和渲染参数时查看 [Manim Community 官方文档](https://docs.manim.community/en/stable/)。
