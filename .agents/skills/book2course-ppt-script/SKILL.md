# 逐页演讲稿与配音文案

以已确认的大纲或现有 `Lesson` 为骨架，保持页号、标题、视觉步骤和来源的对应关系。若用户只给教材，先形成必要的逐页结构，再写讲稿。

- 每页写可自然说出的完整讲解：引入本页目的，解释条件和因果，用具体例子帮助理解，再过渡到下一页。画面只放提示词和必要公式；讲稿补充解释，不逐字朗读画面要点。
- 为分步出现的卡片、公式或流程写简短的播放提示，例如“显示第 2 步后解释边界条件”。播放提示与实际口播文本分开，避免被 TTS 读出。
- 对 PDF 中的事实保留页码和原文摘录，明确区分引文、转述和教学补充。不要编造引文或把 OCR 猜测写成确定结论；有疑问时列为人工复核项。
- 句子适合中文口播。为公式、缩写、英文术语和数字补充读法；需要停顿时使用自然标点。讲述长短由内容和用户要求决定，不套固定视频时长。

交付时按页号给出“画面提示 / 口播正文 / 显示或停顿提示 / 来源与核查项”。若文案用于当前视频链路，把口播放入 `LessonSegment.narration`，画面短句放入 `bullets`；查看 `zhijiang/models.py` 的字段限制，且不要把播放提示混进 `narration`。
