# 中文教材基准 v3：人教版

这轮使用人教社官方电子教材原页，不把英文教材翻译后称作中文教材，也不使用原创补充读本替代出版社教材。目前取得 **7 组 × 2/6/12 页 = 21 个纯图像 PDF 输入**。教材准备完成不等于 Agent 已通过测试；实测进度以本机结果目录为准。

## 领域与内容

| 学科/学段 | 人教版教材 | 选题 |
|---|---|---|
| 初中数学 | 九年级上册 | 直线与圆、三角形内切圆 |
| 高中数学 | A版必修第二册 | 随机抽样 |
| 语文诗词 | 统编高中必修上册 | 短歌行、归园田居及第三单元诗词 |
| 英语语法 | 九年级全一册 | 中文 Grammar 附录；12页另附课文注释 |
| 物理 | 八年级上册 | 光反射、平面镜、折射开篇 |
| 化学 | 九年级上册 | 分子、原子与原子结构开篇 |
| 生物 | 七年级上册 | 细胞分裂与生物体结构层次 |

官方入口：[人教社教材电子版](https://jc.pep.com.cn/)。具体书籍 ID、电子阅读器页码、印刷页码、原图版本 SHA-256 和非连续选页顺序固定在 `spec.json`。在线书可能更新，因此使用已记录的原图哈希，不仅凭书名重下。

大学数学已查到人教社[《微积分学习指导（经管）》官方产品介绍](https://www.pep.com.cn/products/jc/ptgdyxjc/gjshywghjc/201906/t20190621_1939655.shtml)，尚未取得可用电子正文，单列待获取。大学组不会以高中内容替代。v1 数据库、地质学、心理学、商业管理的中文版本也未计入这7组。

## 文件类型与使用范围

官方阅读器这7份书提供页面图像，保留教材布局、原图、署名和原有水印，转换成无隐藏文字层的 PDF，属于需要 OCR 的数字图像教材，未模拟手机拍摄、污渍或歪斜。文件按原图比例排版，150 DPI 仅用于确定 PDF 物理尺寸，不重新缩放或加工原图。

**原生文字版尚未取得。** 不能使用同一个模型的 OCR 输出给 PDF 补文字层，再把它称为独立的文字提取基线。没有人工全文转录时 OCR F1/准确率留空；引用、公式和文字质量对照原页人工检查。文字版本或大学正文补齐后新建冻结数据集和独立运行目录，保留本轮定义与结果。

原页水印注明“仅供个人学习使用，未经授权不得另做他用”。本机选段与本机学习输出按此范围处理，**未取得教材再分发授权**；教材不是 MIT/CC 开放教材。Git 仅保存来源清单、程序和评估定义，教材、原图、生成结果、缓存和配置均在忽略的 `data/`。个人学习 ZIP 提供给同一用户在本机使用，不能当作可公开分发的数据集或对外上传发布。

## 准备与运行

通过官方目录进入阅读器，完成需要的人工验证；只保存选定页面，不去水印、不绕过登录验证、不批量下载完整教材。每份原图记录在本机 `sources/<id>/acquisition.json`，包括选页顺序、原 URL、相对文件名和 SHA-256。导入程序检查每张图与 `spec.json` 固定指纹，拒绝漏页、重复页、被修改的图和目录外引用。

```powershell
.venv\Scripts\python.exe scripts/benchmark_chinese_textbooks.py prepare
.venv\Scripts\python.exe scripts/benchmark_chinese_textbooks.py run --model qwen3-vl:8b-instruct
.venv\Scripts\python.exe scripts/benchmark_chinese_textbooks.py report
.venv\Scripts\python.exe scripts/benchmark_chinese_textbooks.py package
```

默认素材在 `data/textbook-benchmark-v3`，冻结输入及结果在 `data/textbook-benchmark-v3-run`。`--root` 指定新结果目录，`--source-root` 指定本机素材目录；已有冻结输入不会覆盖重做。没有原页文件时导入命令会明确报缺失，不会自动制造教材。`--cases` 可选择已冻结案例，选取后必须如实报告样本范围。

测试使用真实生产 Agent、本机 Ollama 和系统语音，禁止 DeepSeek 和云模型。与 v2 使用相同的通用教学偏好、学术课堂模板、自动配图和动画模式；不把答案、rubric、人工图形坐标或专用分镜传给 Agent。同一 GPU 依次执行 v2/v3，运行中冻结生产代码；新改进使用新目录对照复测。

## 评价与交付

- 工程：首次完成率、解析/OCR页数、阶段耗时、token、备注、封面结尾、可播放完整 MP4。
- PPT：纯静态教学页，嵌入音视频数量为0；演讲是额外的独立视频。
- 教学：对照原页检查知识、条件、例句、数值、SVG 端点/标签/比例与实际动画。数学/科学需要实际对象或状态变化，不以卡片淡入、流程图或像素差异替代。
- 可视表达：图示、引线、符号和插画服务本页知识；同时检查字体、遮挡、留白和版式变化。
- 评价锚点只统计提及，人工判断独立记录；未测试、未复核保持原状态。失败原因、改进、复测与首次结果分开。

交付介绍、输入页码映射和指纹、实际统计、讲稿/SVG/关键帧证据与改进记录。报告先介绍已验证能力与适用场景，保留真实失败数和覆盖缺口。个人学习教材包用显式白名单打包21份PDF与说明、来源、指纹；不打包配置、密钥、模型、缓存和不相关私人教材。
