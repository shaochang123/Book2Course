# Agent 与模型能力诊断及修复

日期：2026-10-08。基于文档整理提交 `cdfe2fb` 后的生成代码、四领域历史失败及本机实际复验。这个报告回答“效果不行是 Agent 还是模型限制”，不把媒体生成成功当成教学质量全部通过。

## 1. 结论与归因证据

**两方面都有问题，工程限制是已证实、可修复的一部分；当前证据不能给两者分配百分比。**

| 现象 | 实际证据 | 归因与处理 |
| --- | --- | --- |
| 定义只讲成局部案例 | 经济学 PDF 第 20 页末尾有完整定义，但原流程只读取原引文前后各三句。 | Agent 检索窗口漏读，已改为标题范围检索。 |
| 第一范式标题配实例页 | 原引用在第 73 页，定义在输入中的第 72 页。 | Agent 只查引用页，已允许重选输入的相邻页，最终引用标为实际第 72 页。 |
| 外文反例对象被改写 | 历史模型把完整字符串 `students saw their` 误写成 `their is`，同一模型的审稿仍批准。 | 模型理解错误与审稿相关性问题；Agent 原来没有字符串边界约束。现按字体提取完整对象，由程序回填，模型只续写中文说明。 |
| 原页小字、放大空白 | 固定小图没有细节面板；PDF 字体切换丢空格，使完整引文搜索失败。 | 执行器/定位问题，已加入完整文字定位、唯一匹配、动态局部放大及共享 SVG 布局。 |
| 四阶段标题却只有部分阶段 | 输入第 212–214 页未包含第四阶段的说明。 | 输入缺口；新范围检查拒绝该标题，要求补充或拆分，不能靠更强模型补造教材内容。 |
| 模型要求额外反例或泛泛背景 | 中间复验的范围审稿把单个反例标题误解为必须多个例子。 | 模型判断也会错误。进一步隔离审稿输入、限制标题承诺范围后该案例完成；保留失败记录。 |

现有多 Agent 是共用客户端的分阶段模型调用，没有独立自治 Agent 集群。知识图谱约束主语、谓词、宾语、条件和来源编号，不能证明翻译正确，也没有跨教材实体库。复杂表格分解、角色互动或三维机制仍缺少相应执行器；更强模型不能自动增加这些程序能力。

## 2. 本轮实际工程改动

1. `teaching_scope.py` 在画图前检索标题所需断言，查看当前页与输入中相邻一页；原始引文留作追溯，不交给独立范围选择者作为答案线索。另行复核标题的操作、否定、条件和明确数量；不能额外要求标题未承诺的例数。每个场景仍使用一个来源页，跨页联合需求或真实缺口明确失败。
2. 已选来源必须形成独立事实，必讲事实必须进入逐步口播。来源、标题、模型配置、范围审批、字符串与计划缓存重新绑定，旧审批和不完整缓存不能直接复用。
3. 文本 PDF 的行内斜体多词示例按真实字体边界提取。完整原文对象由程序回填，模型只能生成中文续写；运行时仍核对原文字符串，不以模型“已保留”声明作为证据。没有按学科或教材标题写示例分支。OCR 没有可靠字体边界，不应用这一保护机制。
4. 原页作为定位图，右侧放大当前讲解依据；SVG 和视频共用裁剪与布局。空格丢失时只匹配完整文字序列，不用词袋拼区域；重复/无法唯一定位时不猜放大区。
5. 外文文本 PDF 的合法数字翻译不再要求整个中文句子逐字出现在英文原文。数字仍须来自引文；OCR、中文数词和新增数值保留严格检查。数值的单位、角色与结论仍依赖含义核对，不能将这个检查称为计算或事实证明。
6. Ollama 的新范围阶段接入已有思考设置与调用预算。诊断脚本记录实际调用指标、失败正文与服务版本；不记录密钥或模型推理正文。

## 3. 实际复验结果

使用已有四领域基线的原始标题、引文、PDF 哈希及选页，提示词为空；模型名称保持 `qwen3.5:9b`，常规复验 `semantic_thinking=false`，本机 Ollama 为 **0.40.0**，语音为 Windows 中文系统语音。未下载或改用更大模型，没有给模型预写节点、坐标或专业分镜。

这是一轮参与调试的案例回归。历史基线的服务版本不同，也未完整保存权重摘要，因此不是严格单变量消融，更不是独立盲测；结果只支持具体工程问题已改善。

| 案例 | 生成及内容检查 | 实际媒体 | 本机证据 |
| --- | --- | --- | --- |
| 语言学：非构成成分的替换失败 | 完整原文字符串保留，不再出现历史错误对象；中文续写仍生硬、节点有重复，教学质量部分通过。 | 21.70 秒视频；有声，原文局部可读。 | `data/agent-audit/bound-objects-linguistics/`。 |

三段媒体均经真实解码验证：H.264/AAC、1280×720、30 fps、非静音，音视频时长差小于 0.12 秒。实际查看了 SVG 的 PNG 和最终视频帧；语言学放大约 5.78–6.99 倍，数据库各步约 5.78–7.68 倍（相对于本页定位小图）。放大表示阅读和讲解顺序，不是专业机制模拟。

另做一次同名模型的思考模式对照：实际范围阶段在 **4096 输出 token 预算**下约 100 秒达到预算而失败。这说明该配置下未得到可用结果，不能据此断言思考无效或更大模型没有收益。之前新增阶段未接入思考控制的诊断已失效，以保存的实际 `metrics.thinking` 为准。

中间范围误选、误审、数字翻译误拒绝、原文字符串解码失败与最终结果保留在忽略提交的 `data/agent-audit*/` 和日志中，没有只保留成功版本。

## 4. 测试与复现

提交前全部测试实际执行结果：**225 passed，1 warning，14.23 秒**，日志 `data/agent-audit-release-tests.log`。警告为 Starlette TestClient/httpx 弃用提示。新增覆盖相邻页/远处定义、缺失范围、跨页误标、失败范围缓存、原文对象绑定与缓存损坏、外文数字/OCR差异、字体空格定位、歧义位置、裁剪像素以及真实思考参数。

在项目根目录运行（先有历史基线目录与对应 PDF）：

```powershell
.\.venv\Scripts\python -m pytest -o addopts='' -q
.\.venv\Scripts\python -m scripts.verify_agent_capability --baseline data/holdout/linguistics-v7 --segments 3 --output data/agent-audit/recheck-linguistics --render
```

其他三个案例分别使用经济学第 1 段、数据库第 2 段、社会学第 5 段。`--thinking` 只切换此次诊断的思考设置，不改 `.env.local`。脚本输出 `comparison.json`、原文范围选择、来源理解、命题、设计、模型调用/错误，以及启用渲染时的 SVG/PNG、WAV 和 MP4。它用于已有失败的复验，不替代从新教材提取课程的泛化测试；教材来源与许可见[原清单](../examples/holdout-sources.json)。

旧成片不会自动被修改，服务须重启后新建任务或重试失败任务才能使用新代码。私人配置、教材和生成物继续忽略提交。

## 5. 尚未证明的能力

没有完成强弱模型的严格同权重/同服务消融，也没有新增未参与开发的盲测教材或整本教材覆盖验收。没有证明任意学科都能得到高质量机制动画。专业措辞、节点身份、无关背景、复杂表格/公式、跨页联合场景和同模型误审仍是后续重点；应记录它们，而非将“通过校验”包装成知识正确。
