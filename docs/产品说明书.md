# 智讲 Agent 产品说明书

版本：首版可运行原型，2026 年 9 月。项目所属行业：教育，涉及个性化学习、教学内容生产与知识管理。项目技术名为 Book2Course，对外名称为“智讲 Agent”。

## 一、产品介绍

教材和讲义中的知识常以长篇静态文字呈现。制作一节有结构、有讲解、有画面的教学视频，需要拆分知识点、组织教学顺序、写讲稿、准备分镜、配音并剪辑。对于小规模课程和个性化需求，这些步骤耗时且难以重复。

智讲 Agent 接收用户自有、获授权或开放许可的**文本型 PDF**，在本地网站中生成一节中文教学课。产品输出课程目标、逐段讲稿、画面要点、对应 PDF 页码与原文摘录，以及可播放和下载的 MP4。首版支持概念卡片、公式分步展示、流程画面与中文配音。演示模式无需密钥，使用确定性规则；真实 AI 模式按知识提取、课程规划、讲稿分镜、讲解检查等阶段调用配置好的模型服务。

首版目标是验证从资料到一节课的完整链路，视频目标时长约 2–4 分钟。全书系列课、复杂动画、扫描件 OCR 与针对不同学习者的个性化课程属于后续扩展方向，目前不宣称已实现。

## 二、设计思路

核心设计是“先找到依据，再组织讲解”。每个知识点和视频片段都包含 PDF 页码与逐字摘录。程序先提供带编号的真实原文片段，由模型选择编号并撰写解释；讲稿阶段再选择已核验的知识点编号。程序在两个阶段都依据编号填入原文与页码，模型不能自行改写引文。结构化数据契约连接各阶段，使演示规则和真实模型采用相同的视频渲染路径。失败任务可以用保留的原 PDF 重新生成。

表达形式由知识类型驱动：概念用要点卡片，公式或复杂度用逐步呈现，流程用连续步骤。视频由受限分镜模板合成，以保证画面可读和自动渲染稳定。页面允许学习者查看讲稿和来源，再决定是否采纳内容。

资料处理遵循本地优先：用户必须确认资料使用权；仅当用户选择在线文本模型或 AI 配音并额外同意时，相关文本或讲稿才发送到配置的外部服务。任务结束后可在网站删除本地 PDF、课程与视频。首版网站仅建议绑定本机地址，不提供公开分享接口。

## 三、设计与开发过程

开发始于仅含 README 与 MIT 许可证的仓库。先把赛事要求拆成可验收交付：产品说明书、独立 AI Coding 过程记录和产品 Demo；再确定本地网站、无需密钥演示、可配置真实模型、Windows 中文语音、一节 2–4 分钟课的首版边界。

实现采用 Python 3.13、FastAPI 和原生网页。PDF 解析保留页码；各生成阶段使用严格的数据结构；SQLite 持久化排队、运行、完成和失败状态；Windows 系统语音或在线语音服务输出 WAV；Pillow 绘制画面；FFmpeg 合成 H.264/AAC MP4。任务在后台顺序处理，服务中断后未完成任务被明确标为失败。

测试覆盖原文提取、扫描件提示、无授权或无外部发送同意、伪造引用、无效原文编号、任务状态、失败重试、服务失败和删除。原创 PDF 经本机 Ollama 文本生成、Windows 中文系统配音与视频合成，当前参赛 Demo 输出 4 个片段，视频时长 3 分 18 秒；确定性演示输出 6 个片段，视频时长 2 分 13 秒。另用用户授权上传的一份 56 页教材验证修复后的流程，截图中的原任务成功重试，输出 3 个片段、约 2 分 23 秒的视频。该教材及视频留在本机，不纳入参赛包。自动检查只验证结构与引文位置，不能证明解释在教学上完全正确，发布或教学使用前仍需人工复核。

## 四、商业价值与创新性

目标用户包括需要快速制作微课的教师、培训团队、学习者和拥有授权知识资料的机构。产品有机会减少从资料整理到初版讲解视频的重复劳动；具体节省时长和学习效果尚未做用户实验，不作为已验证收益陈述。未来可以按生成时长、团队协作或私有部署提供服务，但商业模式仍需客户验证。

首版的创新重点是将“资料中的依据、教学逻辑和视频画面”连接为可检查的流水线，而非只做 PDF 摘要或朗读。分阶段模块与来源引用为后续章节连续性、学习者难度适配、人工反馈修订留出扩展点。确定性演示与真实 AI 模式分开标识，使评委能够复现产品，也能区分工程演示和模型生成能力。

## 五、AI Coding 工具使用情况（独立重点材料）

本项目使用的 AI Coding 工具为 **OpenAI Codex**。本届首版的需求拆解、架构设计、代码编写、测试设计与执行、调试和文档编写均通过与 Codex 的交互完成。完整交互阶段、Codex 的具体用途、验证命令与真实结果单独列于《AI Coding 全过程》，作为本说明书的独立附件，不以“使用 AI 写代码”一句话概括。运行产品时可选的文本/语音模型服务是产品能力，不应与开发所用 AI Coding 工具混淆。

## 六、首版限制和提交内容

首版面向文本型 PDF，扫描件不执行 OCR；单机一次顺序处理任务；默认从文档前部选取内容生成一节课。真实模型阶段目前接收前 12 个有文字页面的摘录，演示模式使用前 6 个合格片段。画面为受限模板，复杂数学证明和丰富动画尚未覆盖。真实模型接口已用本机 Ollama `qwen2.5:7b` 与模拟兼容服务验证；其他模型的效果仍取决于具体模型能力。参赛视频使用模型生成的文本讲稿和 Windows 系统语音，未使用 AI 语音模型。

提交材料包括本产品说明书及其独立 AI Coding 附件、可播放 Demo MP4、原创示例 PDF 和本地网站代码与操作说明。示例讲义为本项目新写内容。第三方程序与组件来源见《第三方来源与许可》。赛事规定的截止时间按 2026 年 10 月 23 日 24:00（中国时间）管理，提交时以赛事平台显示为准。
