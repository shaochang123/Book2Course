# 数学构造修复与联合验收

日期：2026-10-09。对应用户要求：完成修复，并分别验收知识、SVG 与连续数学动画。**本报告的最终结论待八组实际成片复核后填写。自动测试通过不等于教材效果通过。**

## 1. 输入与验收方法

固定输入为[来源清单](../examples/math-level-sources.json)中的八组公开教材选页，覆盖四个学段。Illustrative Mathematics 使用 CC BY 4.0，OpenStax 使用 CC BY-NC-SA 4.0；教材原文件、商标、输出媒体和配置保留在忽略提交的本机 `data/`。这些教材都参与了调试，结果不是独立盲测，也不代表完整学段或整本教材覆盖。

| 案例 | 学段 | 原 PDF 物理页码 | 必须核对的主问题 |
| --- | --- | --- | --- |
| primary-angles | 小学 | 5 | 点、线段、射线、平行/相交、共同端点的角；所称图形须与画面一致。 |
| primary-fractions | 小学 | 3 | 两个三明治公平分配；每人是一个三明治的三分之二、全部总量的三分之一。 |
| middle-triangle | 初中 | 3 | 实际三角形内角及平角关系；不能用独立任意角冒充三角形的角。 |
| middle-pythagoras | 初中 | 6、7 | 直角前提、实际边上的正方形面积和来源算例；不把数值示例说成一般证明。 |
| high-parabola | 高中 | 1053 | 轨迹的焦点/准线等距、真实顶点、对称轴及焦点弦。 |
| high-logarithm | 高中 | 442 | 正底数且不为一、正自变量、指数逆映射、原页例子。 |
| university-polar | 大学 | 575、578 | 带符号坐标、象限、正负角及负半径；长度不能冒充带符号坐标。 |
| university-taylor | 大学 | 507 | 自然对数在一处的有限展开、实际导数系数、局部误差；该页没有下一页的 Figure 6.5。 |

验收工具 `scripts/verify_math_web.py` 从真实 HTTP 上传开始：原 PDF 哈希 → 选页上传哈希与页码映射 → 实际模型规划 → SVG → 系统语音 → MP4 / PPTX → 下载。生成前后及每个案例开始时核对所有应用 Python、网页与 PowerShell 文件哈希。每步抽取实际视频运动中间帧及完成后画面，不以 SVG 代替视频。全视频解码、非静音音轨、PPTX 内嵌 SVG/MP4 只表示技术检查；完整人工听辨与 PowerPoint 放映另列。

模型只收到相同的通用提示、公开选页和程序反馈，没有教材名称分支、人工坐标或预写分镜。程序不会把自动完成改成 `accepted=true`；来源、SVG、实际运动及网页需人工核对。

## 2. 通用修复

1. 原页图像与原文一起识别复杂公式；保留原文语言和条件，复核可清除虚构图示。原页缓存及外层解析缓存使用新版本并绑定图像、文字、模型与服务地址。
2. 模型分阶段规划教学意图、数学对象依赖图和操作。点坐标、垂足、中点、刚体变换、面积分割、等距轨迹、逆函数、有限展开由通用数学构造计算，有限展开的系数从原函数导数求得。
3. 操作的测量工具由实际对象清单生成类型契约，距离、带符号坐标、面积、夹角/有向角、函数值和导数不能混用。比例的分母也绑定实际对象；参数恒等式不算核心关系核验。
4. 旋转后的实际边长和面积先化简，再生成受限表达式；没有扩大表达式限额来放过错误。SVG 与视频保持等单位坐标，点名锚定真实动点，对应点与曲线保持身份颜色。
5. 分开检查全程不变量与指定步骤终点结论。规划采样及渲染逐帧都测量真实几何，不能用最终成立掩盖错误过程。
6. 一轮有效构造立即进入操作、校验和复核，包括最后一轮；修复请求带被拒候选及具体错误片段。清单编译保留控制量的符号依赖，缺少控制参数或持续失败的操作返回构造层。
7. 设计草稿不是教材事实。视觉与文字审稿只核对原页及实际程序，不能把模型自己补造的证明目标当作教材要求。
8. 完整 JSON、格式、有限预算恢复与服务失败分别处理。Ollama 云模型即使通过本机地址调用也要求发送许可；实际模型角色与调用次数保留。私人教材与配置没有用于云验证。

9. 相邻有限边按共同端点计算顶点内角；有向角弧可传完整扫角，实际端点必须落在真实边方向，直接角测量显示弧度单位。
10. 复杂渲染表达式拆为有界的派生依赖节点，符号证明保留原表达式。镜头优先有限锚点，裁去无关函数远端，保持等单位。
11. 数值口播只修复具体出错句；原页图片直接进入视觉复核，来源、几何、运动三项观察先于批准。规划、视觉和独立复核可分别配置，独立复核使用与规划不同的模型；记录各职责的实际调用。暂态云服务错误至多重试两次，失败不算规划成功。

12. 刚体变换共享对象身份；原图显式隐藏或标为淡化参照，防止出现额外主体。角弧、圆及函数曲线支持刚体变换，参数曲线测量点由真实曲线表达式计算，可检查拼接端点。
13. 从原文独立建立来源覆盖清单，逐字绑定出处；候选完成后逐项检查必要条件、结论、核心算例和实际几何端点。清单不能由候选稿倒推，也不能只核对模型自称已覆盖的列表。数学步骤可按来源安排 3–10 步，避免省掉条件以凑短课；完整简短口播不强行补字。
14. EOF 缺少完成标记与格式错误分别处理。即使正文看似完整也不接受中断响应；相同请求最多两次带退避重试。数学格式最多三次恢复，编号明确从一开始，恢复后仍验证完整契约。

15. `align` 根据源和目标的真实锚点及方向计算连续刚体对齐，保持长度及面积；每帧检查进度与方向非退化。角度的和及差同样标明弧度，不以常数角度和代替正确拼接。
16. 来源要求中的核心主语绑定实际对象类型、顶点数、可见步骤与测量依赖图。多边形可表示为一个多边形或单个封闭的有限边环。仅有无关占位图形、缺少原页主语或主语未参与测量都会被拒绝；结构检查仍不证明讲解语义正确。
17. 核心语义构造持续失败时最多重新设计两次，避免只围绕错误初稿改写坐标；被拒设计与修订保留。概念照片、装饰插图与有计算结果的已解算例分开处理，正确等价示意可用于概念解释，核心算例的值与条件仍须保留。
18. 来源清单选择受限的原文编号，由程序直接填入每条原文及出处；不让模型重打引文。跨段事实保留多条独立出处，不伪造拼接句。图形错误即使同时指出 objective 不成立，也返回构造层，不能靠改写目标掩盖错误对象。

19. 来源清单先对照原页图像生成，再独立核对含义，最多三轮修复；防止翻译或主体整体错误污染设计。记录原清单、具体拒绝与改正，而非事后改写失败报告。
20. 构造工具返回实际坐标、面积、长度及角度，提前检查现有对象与自由度能否表达必讲内容。通用线线/圆圆交点由真实对象计算并逐帧核验；混合线圆交点明确不支持。
21. 直线与射线共享视口裁剪及延伸，SVG、数值核验和 Manim 使用同一几何；曲线动点即使隐藏也须在真实绘图区间。
22. 完整行为 JSON 只修复无效字段，保留有效关系与角色，记录改动；损坏 JSON、缺失核心字段或服务失败仍明确拒绝。恢复后保留全部数学、来源、SVG 和实际动画门槛。
23. 中文分数口播不能绕过计算绑定。误差线收合和动点暂时重合按全部运动采样判断，不以单个终点冒充全程退化；真正全程退化仍拒绝。
24. 推理档位依据实际服务元数据配置；数学格式恢复的额外预算槽仅适用于第三次首次触及输出上限。更换档位、模型组合及框架均记录，不能归为模型固有能力排名。

25. 构造补丁只新增、替换或删除受限对象，保留正确依赖并重新排序；拒绝循环、悬空、参数对象同名与不存在的分割子格。两个不同措辞的行为失败也会返回构造层。草稿容量为 32，分割后核心 48、含点名渲染 64 的上限保留。

26. 来源覆盖及构造可表达性按每批两项处理，保留所有编号和拒绝项，后续服务失败不会返回部分成功。来源生成与含义审稿采用一致的数学范围，排除背景历史，并按整份清单核对公式/算例，不要求同一事实重复出现。
27. 修复声明参数后缀被误当成对象坐标依赖的循环误报；实际被拒的二十项构造重放已编译通过，仅作为工程诊断。真实点坐标重名仍拒绝。函数图像也可表示参数曲线 `(t,f(t))`，不因等价表示误拒绝；来源关系与实际运动检查保留。
28. 审稿接收明确的一步一号、实际 SVG 图像位置、终点参数和测量，不能把初值或教材图像序号当作某步状态。自由口播每步最多三次修复，持续无效仍拒绝。
29. 对数成片再次暴露模型将元数据中的条件当成已讲内容。来源说明改为程序逐字取用已核对中文清单，放入真实说明卡、配音及讲稿；定义和条件先讲，卡片结束后再开始数学运动。来源说明与动态测量分开，自由口播仍拒绝未绑定数字。来源卡不能当作数学推演通过，复现工具另抽取真实数学运动帧。
