## 2. 架构与编码用途

Codex 用于设计来源、知识、课程、场景和媒体之间的数据契约，编写 FastAPI/SQLite、模型与语音适配、PDF/OCR、SVG/Manim、视频和 PPTX 导出，并设计模拟服务和回归用例。程序负责选择编号回填、输入/状态、数值与渲染；模型建议仍受来源和执行约束。

本轮文档以[架构与接口](架构与接口.md)映射真实模块，以[实现状态](实现状态与路线图.md)将原型建议和当前 API 分开。没有将所有 Agent 说成独立进程，也没有把结构化输出或模型批准称为专业事实证明。

## 3. 真实调试案例：关系图与来源

四领域首次生成暴露社会学研究传统连线、经济学对象/成本身份关系、语言学例句字体切换和数据库原页定位等错误。部分错误被同一模型的审稿放过，不能凭模型 approved 断定正确。

Codex 根据这些实际失败增加独立命题、方向/条件绑定、保守身份检查、完整外文名称、位置文字提取、完整摘录定位和审稿摘要失效规则。标签布局与小数字号 PNG 渲染也经过真实输出修复及回归测试，没有按教材标题写分支或提供专属坐标。

最终四份媒体通过技术检查；外文例句和部分主题范围仍未完全合格，报告保留缺陷，不把人工修订后的内容伪装成原始模型成功。四本均参与调试，最终结果不是独立盲测。

## 7. 四个学段的数学教材验证与修复

用户要求覆盖小学、初中、高中和大学，并检查真实数学 SVG 与连续演示，不能用流程图替代，也不能用已有专题规则的材料证明泛化。Codex 选择八组公开教材选页，记录原文件哈希、物理页码和许可，查看原页，编写自动知识点隔离验证工具；未给模型预写知识点、坐标或数学分镜。

实际输出暴露了伸缩冒充旋转、抛物线动点离开曲线、勾股算式不相等却口播相等、错误顶点及关键对象离开画面。Codex 对照源页、对象表达式、SVG 和视频中间/末帧复核，将技术生成成功和数学质量拒绝分开记录。修复包括完整来源批次、通用参数曲线、等单位视口、稳定图层、受限参数变更、实际方向测量、来源绑定的几何关系、可见点窗口检查、字段级格式反馈与缓存失效；没有为上述教材写专题分支。

本轮最后完整回归 **255 passed，1 warning，15.47 秒**，日志 `data/math-levels/release-tests-v11.log`。新窗口检查曾导致两个原关系测试失败，扩大测试正例窗口覆盖其真实坐标后全部重跑通过；没有放宽实际关系测量。原创执行器探针的圆弧、圆周点和逐帧约束通过，但它不计为教材自动生成成功。

本机 9B 推理出现停滞后，保存部分实验并用已安装 7B 串行进行大学尝试；保留各阶段代码哈希、模型变化及中断，未把更换模型说成受控性能比较。公式提取缺口、模型几何规划与审稿误判仍在；没有声称达到 3Blue1Brown 制作水平。材料、实际结果与复现见[数学教材验证](math-level-validation-2026-10.md)。
