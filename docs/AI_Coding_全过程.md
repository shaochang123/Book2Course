## 2. 架构与编码用途

Codex 用于设计来源、知识、课程、场景和媒体之间的数据契约，编写 FastAPI/SQLite、模型与语音适配、PDF/OCR、SVG/Manim、视频和 PPTX 导出，并设计模拟服务和回归用例。程序负责选择编号回填、输入/状态、数值与渲染；模型建议仍受来源和执行约束。

本轮文档以[架构与接口](架构与接口.md)映射真实模块，以[实现状态](实现状态与路线图.md)将原型建议和当前 API 分开。没有将所有 Agent 说成独立进程，也没有把结构化输出或模型批准称为专业事实证明。

## 3. 真实调试案例：关系图与来源

四领域首次生成暴露社会学研究传统连线、经济学对象/成本身份关系、语言学例句字体切换和数据库原页定位等错误。部分错误被同一模型的审稿放过，不能凭模型 approved 断定正确。

Codex 根据这些实际失败增加独立命题、方向/条件绑定、保守身份检查、完整外文名称、位置文字提取、完整摘录定位和审稿摘要失效规则。标签布局与小数字号 PNG 渲染也经过真实输出修复及回归测试，没有按教材标题写分支或提供专属坐标。

最终四份媒体通过技术检查；外文例句和部分主题范围仍未完全合格，报告保留缺陷，不把人工修订后的内容伪装成原始模型成功。四本均参与调试，最终结果不是独立盲测。
