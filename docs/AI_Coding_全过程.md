Codex 建立隔离 `.venv-tts`、固定 SDK/模型版本、权重哈希和安装记录。常规整文件下载出现断流，改用可恢复分段下载并对照官方 SHA256；没有关闭 TLS 验证。依赖安装因最新 Gradio 与固定 Transformers 不兼容而回溯，核对官方包约束后固定 Gradio 5.49.1。CPU Torch 先验证安装，再安装官方 CUDA 构建。参考、权重、配置和试听均被 Git 忽略。

Codex 实现兼容语音服务、提示缓存、模型身份检查、WAV 校验、生成长度上限、空闲释放，以及默认声线试听和新网页默认 AI 配音。实际 1.7B 短句速度不足，CUDA int8 仍慢；CPU 动态 int8 达到生成限额而被拒，故不作为可用配置。实测 0.6B 浮点模型后选为本机默认。一次试听命令的自动权限审核超时，受限执行又因本机套接字权限失败；明确记录后以本机权限重新成功执行。

长讲稿实际网站验证又发现整段预填模式耗时异常。Codex 保留原任务失败，改成标点保持、最多 50 字切段与模型默认增量文本模式，再经 API 重试；完整 WAV 交付仍为非流式 HTTP。一个片段失败不能返回部分成功；模型名字不能伪装权重大小。健康接口改为合成中立即返回忙碌状态，等待时限通过配置传至实际语音客户端。

最终软件回归为 **482 passed，1 warning，59.17 秒**，日志 `data/voice-tests/chunks-release.log`。参考、试听和实际课件的模型调用及媒体/转录检查另见[验证与验收](验证与验收.md)。模拟工程测试、真实推理和听感分别记录，不用音高统计宣称与参考片声音一致，也不以本次配音替代数学联合验收。

## 2026-10-10：素材检索、共享画面与跨领域修复

用户要求建立领域素材库、减少小字、PPT 与视频同步，随后指出原创符号太大、摆放生硬且不是真正的手绘，要求参考实际 NotebookLM 视频并从网上寻找素材。Codex 对照参考视频关键帧，改成与实例和观点绑定的小配图、开放留白和内容对比。原来 100 个程序绘制 SVG 保留并明确称为线条符号；实际查看、许可核对后导入九个 CC0 手绘条目，记录作者、原页、源哈希和书本的裁切区域。没有复制参考视频中的图案，也没有将外部素材称为原创。

Codex 编写目录元数据读取、安全校验、本地索引、候选检索、模型受限选择、SVG 与透明 PNG 包装、共享页面与逐步呈现；PPT 和完整视频使用同一正文布局，连续数学场景保持原有运动。网页与创建/重试接口保存自动配图选项，素材目录变化使缓存失效。每级素材目录有说明，源码、安装包与缓存区分开。

用户继续要求泛化，Codex 新建并冻结放大镜、图书查找、蝴蝶发育和抽象逻辑四份原创短资料，用同一模型、提示词和程序，不指定素材 ID。实际运行发现课程标题漏用、同一对象重复候选、唯一候选在同页重复三次、部分结构被整器官插画冒充、英文子串误匹配和关键句被拆成残页。通用修复包括标题的 Literal 与输入次数约束、相关标签和对象同义名分开、词边界、优先配图去重、候选数量进入输出契约、真实对象名称作图片标签、逐页修复及整句排版。

继续查看成片帧发现：逻辑课口播正确，屏幕短句却写反推导方向，原有同模型审稿未拦住。物理课的额外逗号片段又丢掉“常见误解”限定，使错说法单独显示。Codex 增加通用讲稿句子绑定，正文和额外补充都保留完整句子：模型只选择已有句子编号，程序填入原句，不为逻辑或电路教材写专题判断。原短句、候选与修改保存，全部选择通过后才修改课程；服务失败和编号错误明确拒绝。完整口播不改写，数学连续场景不替换为静态插画。新增步骤也使原模拟测试的回复队列失配，按真实阶段更新模拟响应并检查画面逐字绑定后重跑。

实际测试、失败/重试、八份输入的范围、成片、配音来源、网页检查和安装包清单见[素材与共享画面验收](素材库验收-2026-10.md)。四份新资料后来参与工程修复，最终属于新资料开发回归；没有把它们称为独立盲测，或据媒体通过宣称所有教材知识完整。
