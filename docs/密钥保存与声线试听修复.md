# 本机密钥保存与声线试听修复

## 问题与修复

- 刷新丢失密钥：原网页不保存密钥，任务只在服务内存中持有。Windows 新增默认开启的本机保存选项，使用当前账户 DPAPI 加密，刷新和重启后以状态提示代替回填明文。
- 试听没有区别：原页面始终使用同一个预生成 AI 音频。现在系统试听实际调用配置的 Windows 声线，AI 试听核对当前服务、模型、声线和文件；切换暂停旧音频并重置播放位置。
- 保存按文本/语音用途、提供方和规范化地址隔离。切换模型或声线仍可使用同一服务的密钥；更换服务地址不会借用其他地址的密钥。
- 输入暂停时可自动保存但不清空正在输入的字段；离开输入框且保存成功后清空明文。保存失败保留输入，并给出可见状态。

旧版未保存的密钥无法从任务数据库恢复，需要重新填写一次。取消“在本机记住密钥”只停止新保存；“清除保存”删除当前地址的保存项，不修改环境配置。

- 在独立本机 QA 服务使用明确的测试占位密钥，实测输入暂停、继续输入、离开字段保存和刷新后“已保存”状态。确认最终测试字符串完整保存，未使用用户真实密钥。

- 修改前确认没有排队或运行中的任务，再重启主网页服务。原有已完成课件和视频仍可访问。本轮未重新调用文本模型生成课程。

## 本地数据与提交

加密文件 `data/private/credentials.dpapi`、测试服务、试听音频、日志和截图都留在已忽略的 `data/`。`.gitignore` 额外排除 `*.dpapi` 与 `credentials.pending`；Git 推送检查核对暂存源码与待推送提交，不输出密钥值。浏览器只存非密钥服务设置；SQLite、课程 JSON 和 API 响应不保存或返回密钥。其他平台继续使用本机环境配置或单次任务输入。

配置方式见[中文配置指南](生成配置与恢复.md)、[English configuration](configuration.en.md)，接口见[架构与接口](架构与接口.md)。

## 当前 AI 模型与音色试听（2026-10-12）

用户进一步要求换 AI 模型、音色时能听到对应声音。新增表单当前选择的试听查询、生成和音频接口：缺少时按“生成试听”，已有时可“重新生成试听”；修改地址、模型或音色会停止旧音频，并按独立指纹加载缓存。模型和音色等非密钥设置在输入时保存，立即刷新也可恢复。

- 全量回归：**849 passed，1 warning，139.66 秒**，日志 `data/selected-preview-tests.log` 和 JUnit `data/selected-preview-tests.xml`。
- 自动测试覆盖四组模型/音色/端点组合、缓存重启、显式重新生成、损坏 WAV、服务失败、外部同意、已保存密钥和错误输入不回显密钥。
- 隔离网页测试使用两种测试模型和两种测试音色，输出不同测试音与时长，验证请求路由、生成途中修改、缓存自动切换及刷新恢复。旧请求完成不会覆盖当前音色；不支持的模型显示错误，并清空播放器来源。
- 真实本机 `qwen3-tts-0.6b-base` / `notebook-reference` 通过新生成接口合成原创文本，耗时 **52.20 秒**，返回 **8.64 秒**可解码 WAV；浏览器成功播放。实际结果记录在 `data/selected-preview-real-result.json`。不同真实模型的听感仍取决于服务实际支持的模型和音色。

所有音频、缓存、测试服务和截图都存入已忽略的 `data/`；本轮未向外部服务发送教材、参考音频或密钥。
