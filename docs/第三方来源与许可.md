# 第三方来源与许可

下列工具通过包管理器或系统接口使用。项目源码、依赖、模型权重和教材资料的许可分别适用，不因仓库采用 MIT 而变成同一种许可。此清单为来源记录，再分发时核对所用版本的许可全文；九月快照另存于归档。

## 运行依赖

- [FastAPI](https://github.com/fastapi/fastapi)，MIT：HTTP API、文件上传与网页服务。
- [Uvicorn](https://github.com/encode/uvicorn)，BSD-3-Clause：本地 ASGI 服务器。
- [python-multipart](https://github.com/Kludex/python-multipart)，Apache-2.0：PDF 表单上传解析。
- [pypdf](https://github.com/py-pdf/pypdf)，BSD-3-Clause：PDF 文本与页码提取。
- [pypdfium2](https://github.com/pypdfium2-team/pypdfium2)，Apache-2.0 或 BSD-3-Clause 双许可：扫描页渲染。
- [RapidOCR](https://github.com/RapidAI/RapidOCR)，Apache-2.0：本机 OCR；所附 OCR 模型的许可与来源见其模型许可说明。
- [ONNX Runtime](https://github.com/microsoft/onnxruntime)，MIT：RapidOCR 的本机推理引擎。
- [Pillow](https://github.com/python-pillow/Pillow)，安装包元数据标示 MIT-CMU：中文教学画面绘制。
- [python-pptx](https://github.com/scanny/python-pptx)，MIT：生成 PPTX 幻灯片、讲者备注和内嵌视频；SVG 通过 OOXML 扩展写入，并附 PNG 兼容图。
- [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)，BSD-2-Clause：定位其 wheel 中的 FFmpeg 可执行文件。
- [HTTPX](https://github.com/encode/httpx)，BSD-3-Clause：兼容模型/语音 HTTP 服务调用。
- [python-dotenv](https://github.com/theskumar/python-dotenv)，BSD-3-Clause：从被忽略的本机 `.env.local` 读取模型配置。
- [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx)，MIT：可选本机 AI 配音的 ONNX Runtime 适配器。
- [Misaki](https://github.com/hexgrad/misaki)，Apache-2.0：可选本机 AI 配音的中文文本转音素组件。
- [Manim Community](https://github.com/ManimCommunity/manim/blob/main/LICENSE)，MIT：可选通用图示、二维教学过程与专用数学推演的 Cairo 渲染器。
- [SymPy](https://github.com/sympy/sympy)，BSD-3-Clause：可选数学场景的符号计算和关系核验。
- [Jieba](https://github.com/fxsjy/jieba/blob/master/LICENSE)，MIT：从当前中文来源提取词语候选，不提供教材专属词表。
- [PyMuPDF / MuPDF](https://pymupdf.readthedocs.io/en/latest/about.html#license-and-copyright)，AGPL-3.0 或 Artifex 商业许可：可选原页图像、区域定位与验证渲染。本机 1.28.2 元数据注明双许可；不能当成 MIT 依赖。分发含此组件的应用时须按实际许可安排核对。
- [NumPy](https://github.com/numpy/numpy/blob/main/LICENSE.txt)、[PyAV](https://github.com/PyAV-Org/PyAV/blob/main/LICENSE.txt)：Manim/媒体检查的间接组件。本机 NumPy 2.5.3 许可表达式含 BSD-3-Clause、0BSD、MIT、Zlib、CC0-1.0，PyAV 19.0.1 为 BSD-3-Clause；原生库与 FFmpeg 的许可另核对。

`imageio-ffmpeg` 的 **Python 包许可**与其附带的 **FFmpeg 可执行文件许可**需分开看。本开发机 wheel 内 FFmpeg 的 `ffmpeg -L` 输出为 GPL 第 3 版或更新版本；[FFmpeg 上游许可说明](https://github.com/FFmpeg/FFmpeg/blob/master/LICENSE.md)和对应构建的许可应随再分发方案核对。本仓库不提交 FFmpeg 可执行文件，安装依赖时由包管理器取得。生成的 Demo MP4 中不包含该可执行文件。

## 开发、示例与系统组件

- [pytest](https://github.com/pytest-dev/pytest)，MIT：自动测试。
- [ReportLab](https://www.reportlab.com/dev/docs/)，BSD：生成原创示例、当前项目说明 PDF 和历史材料 PDF。
- [Windows System.Speech](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer)，Microsoft Windows/.NET 系统组件：本机中文系统配音。视频和网站均标示该声音不是 AI 配音。
- [Ollama](https://github.com/ollama/ollama)，MIT：本机运行文本模型。应用使用其[原生结构化输出接口](https://docs.ollama.com/capabilities/structured-outputs)；Ollama 程序与模型权重均不提交到本仓库。
- [Qwen2.5:7B](https://ollama.com/library/qwen2.5)，Apache-2.0：九月历史 Demo 的本机文本模型，用于知识提取、课程规划、讲稿分镜与检查；不用于配音。模型权重不随代码分发。
- [Qwen3:4B](https://ollama.com/library/qwen3:4b)，Apache-2.0：当前本机配置模板选用的文本模型；模型权重不提交到仓库。
- [Kokoro-82M v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)，Apache-2.0：可选本机中文 AI 配音模型。[ONNX Community 的量化导出](https://modelscope.cn/models/onnx-community/Kokoro-82M-v1.1-zh-ONNX)及音色按需下载到 `data/`，不提交到仓库或参赛材料。
- 原创二分查找示例讲义和开发者分镜为项目示例；真实教材/用户资料的衍生产物另按各自来源管理，不宣称为原创教材。
- 数学动画验证使用 [MIT OpenCourseWare《Linear transformations and their matrices》](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/resources/mit18_06scf11_ses3-6sum/)，18.06SC，2011 年秋。原理与引文注明 PDF 页码；中文解释、数值例子与动画为补充制作。MIT 资料按其 [CC BY-NC-SA 4.0 许可](https://ocw.mit.edu/pages/privacy-and-terms-of-use/)标注，本地测试 PDF、PPTX 和视频保存在忽略提交的 `data/`，不混入程序代码许可。
- 通用场景的真实 PDF 测试使用 [MIT OpenCourseWare《Geometric definition of the derivative》](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/resources/mit18_01scf10_ses1c/)，18.01SC，2010 年秋，使用相同 MIT 许可与来源标注。五学科回归参考 PDF 和分镜为原创示例，明确注明开发者编写，不冒充模型自动规划验收。

九月本机 Ollama 0.34.1 的 `/v1/audio/speech` 实测为 404。项目的本机 AI 配音由独立 Kokoro 服务提供，历史 Demo 使用 Windows 系统语音。实际更换模型或供应商时记录服务名、模型与条款，不把历史验证的接口行为推广到所有版本。
