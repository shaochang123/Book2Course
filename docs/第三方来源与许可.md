# 第三方来源与许可

- [resvg_py 0.5.0](https://pypi.org/project/resvg_py/)：透明 SVG 渲染依赖，使用 [MIT 许可](https://github.com/baseplate-admin/resvg-py/blob/master/LICENSE)。本机安装了 Windows x64 的 CPython abi3 wheel，无需系统 Cairo。底层依赖仍按各自发行许可管理。
- `zhijiang/assets/visuals/` 的 100 个领域线条符号由 Book2Course 原创，采用项目 MIT 许可；不能将其称为外部艺术家的手绘作品。
- 五个 `handdrawn/` 子目录包含 9 个有出处的手绘插画条目，采用 [Openclipart 的 CC0-1.0 许可](https://openclipart.org/share)。西瓜和苹果为 Firkin 对 pencilparker 原画的矢量化；书本为 GDJ 上传的 2016 年 Pixabay 手绘作品，两项为同一作品裁切；电脑、放大镜、灯泡、肺部、蝴蝶的作者分别为 lmproulx、bitterjug、m1981、johnny_automatic、teck5。每项 README 均给出原作页、作者、用途和限制，外部作品不能标称项目原创。未把 NotebookLM 视频中的插画截取入库。

下列工具通过包管理器或系统接口使用。项目源码、依赖、模型权重和教材资料的许可分别适用，不因仓库采用 MIT 而变成同一种许可。此清单为来源记录，再分发时核对所用版本的许可全文；九月快照另存于归档。

## 参考视频与新模板

用户提供的 NotebookLM 参考视频及所附教材用于本机分析教学表达，随后依用户要求提取短段声音用于本机参考配音。程序不包含参考片的插画、长段文字、标识或音频；参考段、转录和新生成的试听均保存在忽略提交的 `data/`。四套内置模板为本项目新写的版式数据、原生绘图与代码，复用既有 python-pptx、Pillow、imageio-ffmpeg 等依赖，没有新增第三方模板包。教材和视频的文件名不作为合法许可的证明。

## 本机参考配音环境

- [Librosa](https://github.com/librosa/librosa/blob/main/LICENSE.md)，ISC；[SoundFile](https://github.com/bastibe/python-soundfile/blob/master/LICENSE)，BSD-3-Clause：本地音频读取、音高统计和可选保音高变速；libsndfile 的许可另适用。
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper/blob/master/LICENSE) 与 [Whisper Small 的 CTranslate2 转换](https://huggingface.co/Systran/faster-whisper-small)，MIT：本轮本机转录辅助验证，不是网站必装依赖，不代表人工听辨。
- [bitsandbytes](https://github.com/bitsandbytes-foundation/bitsandbytes)，MIT：单独安装的可选 CUDA 语言层 int8。最终本机 0.6B 配置不使用量化；没有量化参考声线编码器或声音编解码器。

该环境不经 Ollama 运行，不依赖向外部服务发送用户参考声音。详细安装、数据范围和局限见[本机自然讲解配音](自然讲解配音.md)。
