# 第三方来源与许可

本项目源码由此次 AI Coding 过程新写，未复制其他产品的源文件。下列工具通过 Python 包管理器或 Windows 系统接口使用；发行本项目的源代码、依赖 wheel、FFmpeg 可执行文件与生成视频是不同的分发对象。提交材料中列出来源，实际再分发依赖时应遵守相应许可全文。

## 运行依赖

- [FastAPI](https://github.com/fastapi/fastapi)，MIT：HTTP API、文件上传与网页服务。
- [Uvicorn](https://github.com/encode/uvicorn)，BSD-3-Clause：本地 ASGI 服务器。
- [python-multipart](https://github.com/Kludex/python-multipart)，Apache-2.0：PDF 表单上传解析。
- [pypdf](https://github.com/py-pdf/pypdf)，BSD-3-Clause：PDF 文本与页码提取；不执行 OCR。
- [Pillow](https://github.com/python-pillow/Pillow)，安装包元数据标示 MIT-CMU：中文教学画面绘制。
- [imageio-ffmpeg](https://github.com/imageio/imageio-ffmpeg)，BSD-2-Clause：定位其 wheel 中的 FFmpeg 可执行文件。
- [HTTPX](https://github.com/encode/httpx)，BSD-3-Clause：兼容模型/语音 HTTP 服务调用。
- [python-dotenv](https://github.com/theskumar/python-dotenv)，BSD-3-Clause：从被忽略的本机 `.env.local` 读取模型配置。

`imageio-ffmpeg` 的 **Python 包许可**与其附带的 **FFmpeg 可执行文件许可**需分开看。本开发机 wheel 内 FFmpeg 的 `ffmpeg -L` 输出为 GPL 第 3 版或更新版本；[FFmpeg 上游许可说明](https://github.com/FFmpeg/FFmpeg/blob/master/LICENSE.md)和对应构建的许可应随再分发方案核对。本仓库不提交 FFmpeg 可执行文件，安装依赖时由包管理器取得。生成的 Demo MP4 中不包含该可执行文件。

## 开发、示例与系统组件

- [pytest](https://github.com/pytest-dev/pytest)，MIT：自动测试。
- [ReportLab](https://www.reportlab.com/dev/docs/)，BSD：仅用于生成原创示例 PDF 与参赛材料 PDF。
- [Windows System.Speech](https://learn.microsoft.com/en-us/dotnet/api/system.speech.synthesis.speechsynthesizer)，Microsoft Windows/.NET 系统组件：本机中文系统配音。视频和网站均标示该声音不是 AI 配音。
- [Ollama](https://github.com/ollama/ollama)，MIT：本机运行文本模型。应用使用其[原生结构化输出接口](https://docs.ollama.com/capabilities/structured-outputs)；Ollama 程序与模型权重均不提交到本仓库。
- [Qwen2.5:7B](https://ollama.com/library/qwen2.5)，Apache-2.0：参赛主 Demo 使用的本机文本模型，用于知识提取、课程规划、讲稿分镜与检查；不用于配音。模型权重不随提交包分发。
- 原创二分查找示例讲义、网页视觉设计、讲稿规则与程序代码：本次项目开发生成，无外部教材、图像、音乐或人物肖像素材。

本机 Ollama 0.34.1 的 `/v1/audio/speech` 实测为 404，未使用 Ollama 语音模型。若以后更换 AI 模型或语音供应商，应在最终材料中补充实际使用的服务名、模型名、生成用途及其适用条款；当前 Demo 未使用线上生成服务。
