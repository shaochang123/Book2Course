## 2. 当前验收结论

四领域选页均完成媒体，但四本都参与了调试，不能视为独立盲测。22 张图示中有 14 段原页讲解，不能算作领域机制模拟。教材主题范围、外文例句与完整音频/课件播放的质量边界见[验证与验收](验证与验收.md)。

“知识图谱”当前指场景内部的来源命题和关系，没有跨教材实体库或整书先修图。数字、来源、审稿摘要和布局检查都有代码；同一模型的含义审查仍可能误判。

本轮增加标题范围检索/复核、输入相邻页重选、完整外文示例程序回填、原页局部放大和定位修复。它们改善当前定性链路，尚未实现跨页联合场景、表格分解执行器或社会过程模拟。实际同模型对照见[能力诊断](agent-model-capability-2026-10.md)，没有把来源高亮当作机制模拟。

数学对象执行器新增 `geometry` 严格模式、参数曲线、等单位坐标和实际方向变化检查；没有按教材主题添加专属规则。它是部分二维执行能力，非四个学段课程效果验收。公式输入、模型构造和实际画面的问题分别记录在[数学教材验证](math-level-validation-2026-10.md)。

严格模式还绑定原文几何关系并测量实际对象，检查可见点与标签锚点的坐标窗口；模型仍可能漏绑/错绑关系。当前受测教材未达到“知识 + SVG + 连续数学演示”的联合验收，不能把执行器探针或媒体解码通过写作教材教学质量通过。

数学修复新增原页图文转录、依赖构造图、类型化实际测量、全程/终点关系、刚体主体身份、锚点对齐及独立来源覆盖清单；来源主语绑定实际类型、数量、顶点数、可见步骤与测量依赖。网页可分开配置视觉、数学规划和复核。该轮自动回归 482 项通过，八组实际教材联合验收尚未完成；详见[数学修复报告](math-repair-acceptance-2026-10.md)，不据测试数量宣布教学质量通过。同一规划和复核模型仍属于同模型审查。

## 3. 后续顺序与验收条件

下列为计划，不是本轮新增能力，也不是已承诺的交付日期。

| 优先级 | 方向 | 达成标准 |
| --- | --- | --- |
| P1 | 知识点选择与来源纠正 | 可查看完整提取结果，选择必修项/排除项，保留理由和版本；不默默删除失败主题。 |
| P1 | 讲稿/分镜编辑与人工审核 | 可修改内容，改变来源/脚本后失效旧审核与媒体；审核状态与生成成功分开。 |
| P1 | 必修单元到镜头的映射 | 每个必修项有镜头或用户确认的排除原因；覆盖率只表示映射，不表示内容正确。 |
| P1 | 专业内容质量 | 修复外文例句保真、标题范围、条件/反例遗漏；新增未参与开发资料，不给专属提示或画面。 |
| P2 | 项目工作台与文档元信息 | 稳定项目/文档 ID、许可和哈希、任务历史、筛选；不泄露内存密钥。 |
| P2 | 阶段恢复、取消与记录 | 独立阶段开始/结束、输入/输出、失败与有限重试；中断恢复不保留失效审核。 |
| P2 | 公式/表格和字幕导出 | 关键公式可人工确认；表格/机制有执行核验；字幕按实际音频生成并纳入版本。 |
| P2 | 课程交付包 | MP4、PPTX、字幕、讲稿、来源、复核记录的版本一致；未审核输出标为草稿。 |
| P3 | 系列课程、机构与个性化 | 先验证用户需求与成本，再增加权限、协作、语言和学习反馈。 |

## 4. 变更原则

维护现有本机生成链路；实现新数据契约时保留旧课程读取。原型菜单、模拟记录和预写 SVG 不能作为新增能力证据。每次实现后同时更新使用指南、两个 README、对应状态和实际验收；无证据项保持未测试。
