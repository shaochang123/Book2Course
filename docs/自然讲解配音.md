# 本机自然讲解配音

[简体中文](自然讲解配音.md) | [English configuration](configuration.en.md#local-reference-conditioned-speech)

## 模型与声线

本机配音使用 [Qwen3-TTS-12Hz-0.6B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-0.6B-Base)，以短段参考声音条件化生成新讲稿。模型与 SDK 使用 Apache-2.0 许可。参考音频从用户提供的 NotebookLM 视频在本机提取，别名为 `notebook-reference`。音频、转录、试听、权重与本机配置放在 Git 忽略目录内。

这条服务通过 `http://127.0.0.1:8766/v1/audio/speech` 输出单声道 PCM WAV。讲稿依照标点分成最多 50 字的短段，保持文字完整，复用同一参考声音提示；使用模型默认的增量文本模式，收集完整声音后返回 WAV，HTTP 本身不流式返回。一个片段失败就返回错误，不能将已生成的前半段作为成功结果。视频和 PPT 继续按实际 WAV 时长对齐。

`Base` 模型使用参考声音，**没有 CustomVoice/VoiceDesign 的自由语气指令接口**；本实现没有把文字提示词标称为可执行的声线控制。含准确参考转录时使用完整上下文提示，否则使用声音嵌入模式。转录错误会影响提示，换参考音频或转录后会重新建立提示。

## 安装和启动

从仓库根目录创建隔离环境。主网站的 `.venv` 不需要安装 Torch、Qwen 或 Gradio：

```powershell
.\.venv\Scripts\python -m venv .venv-tts
.\.venv-tts\Scripts\python -m pip install torch==2.10.0 torchaudio==2.10.0 --index-url https://download.pytorch.org/whl/cu128
.\.venv-tts\Scripts\python -m pip install -r requirements-tts.txt
.\.venv-tts\Scripts\python scripts/download_qwen_tts.py
```

没有可用 NVIDIA GPU 时，Torch 安装地址换为 `https://download.pytorch.org/whl/cpu`。模型主权重约 1.83 GB，配套语音解码器约 0.68 GB，CUDA 运行时还需额外空间。首次下载耗时取决于网络；模型初始化只使用已经下载的本地文件。

从自有或授权的声音中提取 3–25 秒清晰参考段；完整句子和准确转录有助于声音提示。工具不调用外部服务：

```powershell
.\.venv\Scripts\python scripts/prepare_voice_reference.py --input "参考视频.mp4" --start 4 --duration 14
```

已有 `.env.local` 时只修改下面这些字段，保留原有模型与密钥：

```dotenv
ZHIJIANG_TTS_BASE_URL=http://127.0.0.1:8766/v1
ZHIJIANG_TTS_MODEL=qwen3-tts-0.6b-base
ZHIJIANG_TTS_TIMEOUT_SECONDS=900
ZHIJIANG_TTS_VOICE=notebook-reference
ZHIJIANG_DEFAULT_VOICE_MODE=ai
ZHIJIANG_QWEN_TTS_MODEL_DIR=data/models/qwen3-tts-0.6b-base
ZHIJIANG_QWEN_TTS_REFERENCE=data/voice-reference/voice.json
ZHIJIANG_QWEN_TTS_DEVICE=auto
ZHIJIANG_QWEN_TTS_CODEC_DEVICE=cpu
ZHIJIANG_QWEN_TTS_QUANTIZATION=none
ZHIJIANG_QWEN_TTS_IDLE_SECONDS=60
```

分别在两个终端运行语音服务与网站，终端按 `Ctrl+C` 关闭对应服务：

```powershell
.\scripts\start_voice_service.ps1
# 另一个终端
.\.venv\Scripts\python -m uvicorn zhijiang.main:app --host 127.0.0.1 --port 8765
```

`auto` 在可用时选择 CUDA，否则选择 CPU。默认音频编解码器在 CPU 上运行，自回归语音模型使用选定设备，以降低 8GB 显卡的峰值占用。CUDA 环境需要足够空闲显存；可将设备改为 `cpu` 后重启语音服务。CPU 通常更慢。空闲 60 秒后释放已加载模型，下一次请求重新加载；只释放此语音进程的资源。每段有生成长度上限，达到上限返回失败，不把截断语音当作完整结果。

本机实测选择 0.6B 的原始浮点配置，并非实时配音。`ZHIJIANG_TTS_TIMEOUT_SECONDS=900` 为每次 HTTP 语音请求提供 15 分钟等待；未配置时保留 300 秒，允许范围 30–3600 秒。网站与试听工具使用相同配置。

可选较大的 1.7B：下载时加 `--size 1.7b`，同时将模型名和目录改为 `qwen3-tts-1.7b-base`。本机该模型已生成短句，但速度更慢。CUDA 的可选语言层 int8 量化需安装 `requirements-tts-int8.txt` 并设置 `ZHIJIANG_QWEN_TTS_QUANTIZATION=int8`；编解码器仍保持浮点。CPU 动态量化实测不稳定，已从可用配置中移除；CPU 使用 `none`。模型别名必须与实际 Base 配置一致，不能只改显示名称。

## 网页试听与使用

语音服务就绪后，在主环境生成原创试听：

```powershell
.\.venv\Scripts\python -m scripts.preview_voice
```

网页显示“听一下默认讲解声线”。试听是预生成文件，不会在点击播放时调用外部模型。网站配置、试听模型/声线/地址及文件校验必须一致；不匹配时不提供旧文件。更换默认语音设置后重生成试听，再重启网站读取配置。

新网页默认选择 AI 配音，由 `ZHIJIANG_DEFAULT_VOICE_MODE=ai` 控制；重开已有任务时保留该任务的配音选择。API 不指定 `voice_mode` 时仍沿用系统语音，以保持兼容。选择 AI 配音后，课件和视频会调用同一本机语音服务；生成失败会明确报错。

## 验证范围

自动检查覆盖讲稿切段、参考文件及哈希、模型/声线错误、空白/静音/无效音频、错误响应、提示缓存失效和试听匹配。生成样例另做 WAV/MP4 解码、语音轨及本机转录核对。转录与音高统计是辅助指标，不能据此断言听感与 NotebookLM 一致；直接试听用于判断音色、重音、停顿和自然程度。

实际模型调用、失败、修正和验证结果记录在[验证与验收](验证与验收.md)。安装后的模型和参考段只在本机使用，生成的新讲稿不需要提交至云模型。
