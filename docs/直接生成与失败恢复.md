# 直接生成与失败恢复

## 默认行为

普通 AI 课件默认 `content_checks=warn`，网页名称为“直接生成”。流程为：PDF → 完整可提取知识点 → 引用页与邻页上下文 → 讲稿、SVG 图示和候选配图 → 对照原文与页图修订 → 静态 PPT 与独立配音视频。`basic` 使用一般图示；`auto`、`visual` 可进一步尝试实际数学对象与连续演示。

不让可选内容修订或对象演示的否定判断使整节课失败。生成后的修订与主体使用同一模型，保存 `content_review=same_model_revision` 和实际修订批次数；全部修订不可用则记录 `revision_unavailable`。这些状态不是独立事实审核，也不是知识正确性证明。原始草稿、修订稿、失败构造与原因分别保存。

修订针对“图中这些矩形”与“所有矩形”、否定、条件、角与对边、数字和单位等来源关系。可选图片输入不被服务支持时改用文字修订，不能猜造原图。教材页图可能发送到用户选择的模型；远程服务沿用教材发送确认。模型选择相关原图的页码与归一化裁切框，程序验证边界、裁切实际 PDF，不让模型填写文件路径。引用信息留在 PPT 备注和本地页面清单。

一般图示保留有依据的箭头、线条、符号、比较、属性和完整英文例句。复杂关系与长标注使用完整展示区，教材原图可单独分页。数学或定量内容可通过通用构造图生成真实点、线、曲线及依赖量，并测量实际对象关系；失败保留原有讲稿与图示。不能由“存在连续变化”推定科学机制已经正确表达，分子、细胞等机制仍受通用构造能力限制。

嵌入式教材图片由 PDFium 返回真实边界，模型仅选择当前候选编号，不能指定文件路径。选中图片先在不接收幻灯片草稿的调用中读取，再修订配套讲稿与画面；两个阶段仍使用同一模型。整页扫描图排除在图片候选之外；扫描与矢量页可以走原页图像裁剪路径。数学演示拆为对象构造、工具计算、动作与测量规划，再检查来源及实际 SVG；修复动作时保留已编译对象，不再因带编号的测量名称重写整个场景。测量值、恒等关系及真实运动仍须核验。

PPT 不包含视频或音频媒体，数学步骤使用静态 SVG/PNG；完整讲稿在备注。单独 MP4 使用同一模板、图示与原图，并在数学片段播放连续演示。同一片段的配音只使用一次。

图示与配图按教材内容规划，没有机器学习、西瓜或教材名称的专用分支。模型返回重复编号时保留首份；遗漏的知识点用其原文讲解补回；无效连线和不属于候选的素材不进入画面。模型可通过 `source_notes` 提醒资料缺口。这些提示在网页结果提示与本地 `teaching-draft/warnings.json` 中记录。每批已完成的生成可续用，输入、模型、模板、思考设置或素材目录变化会使对应缓存失效；严格与直接模式的知识提取缓存分开。

封面、学习路线与结尾使用共享画面。结尾由模型从完整讲稿句子中选择可迁移的知识结论，程序复制原句；不把课程最后几段的组织、期刊介绍自动当总结。该制作步骤失败时提示并保留已有导航，不否决课程。

## 引文与完整上下文

短引文用于定位和展示出处，不代表模型只收到这段引文。直接制作讲稿与图示时提供完整引用页及其相邻页，允许模型读取跨句、跨页定义的条件，避免把 300 字摘录上限误当成教材丢失内容。页码及摘录由程序按已有知识点绑定。

输出是可审阅草稿，引用身份检查不能证明每个知识断言正确。模型无法确认完整定义时，应自然说明缺口，只讲现有资料支持的部分。

## 可选严格模式与实际错误

网页选择“严格复核”，或 API 提交 `content_checks=strict`，启用原有来源范围、事实、画面与含义审核流程。创建及重试接口都保存该策略；旧任务缺少字段时读取为 `warn`。

数学对象 `geometry` 与专用数学 `math` 仍使用已有来源、数学及动画复核工作流。损坏 PDF、模型连接中断、无效结构、无法渲染或编码的错误仍会显示。课程长度和模型输出没有新增总额度。

直接生成模式的 AI 语音服务不可用时，自动改用 Windows 系统语音，并重新生成前面所有音频以保持整节课声线一致。课程的实际 `voice_mode`、网页说明和备注会披露切换，不把系统语音标为 AI 配音。严格和数学模式仍显示配音失败。自然声线需要另外运行 `scripts/start_voice_service.ps1`，配置地址不等于服务已经启动。

任务数据库的中断恢复只在 Web 服务获得数据目录的进程锁后执行。创建 `JobStore`、导入应用模块、收集测试或启动第二个服务不会再将正在生成的任务误标为失败。服务退出后由操作系统释放锁，无需删除残留锁文件。

## 使用

刷新网页，选择真实 AI、所需模板，内容检查保持“直接生成”，提交资料。旧失败任务点击“使用原 PDF 重新生成”即可使用网页当前选择。也可以提交：

```powershell
Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8765/api/jobs/你的任务ID/retry' -Body @{content_checks='warn'}
```

这轮采用取消内容审核阻塞的方案。运行中的 Agent 尚未接入网络检索；不能仅放一个名为 web-search 的 Skill 文件就声称模型已经具备联网能力。若后续接入，联网补充资料需要独立 URL 与来源类别，不能伪装为教材的 PDF 引文。

## 2026-10-13 接口与数学演示修复

直接生成的 `auto`、`visual` 会使用所配置的数学规划与复核模型。场景成功后更新为大幅版式，旧的窄幅规划在重新导出时也会调整。数学步骤必须有实际关系覆盖，差异用 `not_equal` 核验，并逐步审稿；失败的候选保留，服务故障不会反复重写图形。

普通讲稿、原图读取与图文对应遵循推理开关。请求关闭推理但服务仍返回推理内容时，记录实际观察，并在后续语义阶段保留服务采样设置，避免强制贪心导致重复。原图对应按来源重新编写，不将被拒旧稿作为答案。

Ollama 云接口省去 `num_predict=-1` 和本地 GPU/上下文参数，避免被转为负数 `max_tokens`。临时 429 按 `Retry-After` 等待；服务明确报告月度额度耗尽时，直接提示切换本机模型或调整账户，不把它叫作本项目的输出预算。
