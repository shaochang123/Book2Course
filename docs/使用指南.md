# 使用指南

适用：当前 0.1.0 本机应用。产品与能力边界见[产品说明书](产品说明书.md)、[实现状态](实现状态与路线图.md)。配置细节见[生成配置与恢复](生成配置与恢复.md)。

## 1. 安装、启动与关闭

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python -m pip install -e ".[test]"
.\.venv\Scripts\python -m uvicorn zhijiang.main:app --host 127.0.0.1 --port 8765
```

已有 `.venv` 时无需重复创建。打开 [本机网页](http://127.0.0.1:8765/)。按启动终端的 `Ctrl+C` 关闭；关闭网页只停止查看，不会关闭后台服务。若还启动了 Kokoro 8766 服务，在其终端也按 `Ctrl+C`。其他程序的服务不用一起停止。

端口占用时先确认原服务终端，或改用 `--port 8767` 并打开对应地址。不要为解决端口冲突结束所有 Python 进程。

可选教学图示与动画：

```powershell
.\.venv\Scripts\python -m pip install -e ".[math-animation]"
```

网页会显示动画环境是否就绪。关系图、流程图、比较图和原页讲解不需 TeX；几何和专用数学推演需 `latex`、`dvisvgm`。安装后重启服务。

## 2. 首次体验

1. 在“开始生成”选择[原创二分查找 PDF](../examples/binary_search_original.pdf)。
2. 选“确定性演示模式”和“Windows 中文系统语音”。
3. 确认资料使用权，点击“生成一节课”。
4. 等待“生成结果”显示完成，展开讲稿并核对 PDF 页码及原文。
5. 播放视频，下载 MP4 和 PPTX；如有需要删除完成任务。

此模式的内容由规则生成，不代表真实 AI 的教材理解能力。只有生成完成才能下载视频和课件；课程 JSON 可早于媒体完成保存，不能据此判断任务完成。

## 3. 真实 AI 与配音

本机 Ollama 启动后运行 `ollama list`，选择实际已安装的模型。网页选真实 AI，接口类型填 Ollama，地址填 `http://127.0.0.1:11434`，模型填实际名称。本机无需 API 密钥。

也可首次复制 `.env.local.example` 为 `.env.local`，编辑后重启；已有配置文件直接编辑。模板不是本机模型安装清单。更换模型后等待当前任务结束或失败，再按实际任务重新生成。

配音方式与文本模式独立。Windows 系统语音无需语音模型；本机 AI 配音由独立 Kokoro API 提供，需按[配置指南](生成配置与恢复.md)安装、下载并启动 8766 服务。外部配音接口须返回 WAV。

外部文本/语音地址需要额外确认发送相关文字，密钥仅在运行期间存在于服务内存；服务重启或失败后重试需重新输入。Ollama 上的云端模型也可能发生外部传输，选择本机已下载模型时核对其运行位置。

## 4. 选择动画和讲解范围

| 设置 | 使用建议 |
| --- | --- |
| `auto` | 对新资料先按内容自动选表达；环境不足时用基础图示。 |
| `visual` | 必须使用通用场景；契约或来源检查持续失败会报错。 |
| `geometry` | 要求真实二维数学对象、函数或参数曲线；需 TeX，失败不改用流程图/原页高亮。 |
| `math` | 仅用于有来源的二维线性变换，不能当作任意数学动画。 |
| `basic` | 基础概念、公式要点与流程模板；内嵌片段静音。 |

提示词可说明目标读者、讲解重点与风格，最长 4000 字符，不能绕过来源和计算检查。网页没有页码范围选择；只讲部分章节时准备相应 PDF，注意裁出的文件会使用新的物理页码。

数学模式的表达式、数值和运动检查不证明知识正确。混合排版中公式可能没有被文字提取读到，需对照原 PDF；四个学段的实际测试见[数学教材验证](math-level-validation-2026-10.md)。短资料允许一个有依据的知识点。

## 5. 查看进度、讲稿与来源

保存 `/?job=任务编号` 链接，刷新或重新打开后可继续查看同一任务。任务编号由创建接口返回，地址由网页更新；当前没有全任务列表或项目搜索。

解析和知识提取显示页/批次进度，本机模型调用显示耗时与正文字符数。低内存、CPU 推理和长教材可能耗时较长；阶段百分比不是预计完成时间。必须保持 Web 服务运行。

结果查看顺序：课程目标 → 片段标题与讲稿 → 原文摘录和 PDF 物理页码 → 场景表达与知识关系 → 视频。关系箭头只表示对应来源谓词；原页高亮不是机制模拟。对 OCR 页同时核对原图，不能只看匹配后的文字。

## 6. 预览、下载与复核

完整 MP4 有配音。PPTX 包含封面、各片段 SVG 摘要页、内嵌 MP4 页及讲者备注。通用/专用片段有配音，基础片段静音；放映时点击播放。PPTX 字段可编辑，SVG 内部不是 PowerPoint 独立形状。

使用前逐项核对定义、适用条件、完整例句、公式、画面和口播。检查音画同步、中文字和发音。自动检查或“生成完成”都不代表已获人工教学批准。

网页提供 MP4/PPTX/可用场景 JSON 下载，尚无独立字幕、审核记录、课程 ZIP 或逐镜头编辑入口。完成任务不能直接重试；需要新生成时重新上传。

## 7. 失败、重试与删除

| 错误 / 情况 | 下一步 |
| --- | --- |
| 资料使用权未确认 | 确认使用权后提交。 |
| 文件类型、损坏、密码保护或超限 | 修正源文件；200 MB 以上分拆资料再上传。 |
| 提取后无可用文字 | 检查扫描清晰度与 OCR；无法恢复的源资料应先人工整理。 |
| 模型或来源核验失败 | 记录任务编号、具体知识点/页码，检查本机诊断，调整模型或范围。 |
| 语音服务失败 | 启动对应服务，核对地址、模型、音色和密钥，再重试。 |
| 动画环境未就绪 | 安装依赖；几何/数学还需 TeX。也可选 `auto` 或 `basic`。 |
| 服务中断 | 重启后任务标为失败，用原 PDF 重试。 |
| 删除返回冲突 | 排队/运行中不能删除，等待完成或失败。 |

失败后调整网页设置，点击“使用原 PDF 重新生成”。符合输入指纹的解析、批次和审核合格分镜可复用；旧草稿仍需审查。更改来源、模型或提示词会使相应分析缓存失效，媒体重新生成。更换外部服务地址需重新提供许可和密钥。

完成或失败可删除本地任务，移除其 PDF、课程、素材与 SQLite 记录。已下载文件要在下载位置自行处理；外部服务留存不受本机删除控制。

## 8. 本机文件与维护

默认数据位于 `data/jobs.sqlite3` 与 `data/jobs/任务编号/`，详见[架构与接口](架构与接口.md)。`.env.local`、`data/` 和导出 PDF 已忽略提交。备份资料时同时保留数据库与任务目录，先停止服务；不要把含授权教材或密钥的本机配置混入源码提交。

当前没有运行任务取消、独立阶段控制或审核停点。这些能力见[实现状态与路线图](实现状态与路线图.md)。
