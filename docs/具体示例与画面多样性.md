# 具体示例与画面多样性

## 本轮要修复的问题

对照用户提供的视频、首次机器学习视频和上一轮生成物，发现两处退化：普通页面被统一的大卡片包住；简洁画面规划把记录、候选比较和算例缩成主题名词。增加图标或随机轮换版式不能修复内容流失。

首次机器学习视频的专用手工渲染脚本只作对照，没有复制其中按教材标题分支的画法到产品。新版依据每段讲稿的具体知识和例子选择表达形式，坐标、SVG、字体、动画状态和媒体拼接由程序生成。

## 规划和渲染

画面规划只能使用已经进入口播的知识。基础 AI 路径先检查讲稿完整使用各个已规划知识点，再检查选中引文中的显式数字算例 / 记录是否丢掉数值。模型重试后仍遗漏时，程序按原样补回完整已选引文及条件，网页 notice 和 `script-coverage.json` 披露该动作，然后继续内容复核。补回的是原文，不是程序自拟算例；这也不证明整本教材已经选全。当前数字覆盖信号只识别具有至少三个不同阿拉伯数字值的显式运算或数字字段记录，不涵盖中文数词、一般代数、证明或完整题目覆盖。

来源提取先连接中文 PDF 的物理换行，再在 300 字引文上限内优先按完整句子、其次按分句划分，保留后续片段。没有可辨标点的长公式仍可能只有字面片段，不能凭程序补出结论。此规则修复单个换行造成“作为金额单位”被拆开的情况；提取缓存已更新版本。验收样例 PDF 按实际字体宽度换行，完整小数和拉丁词不在中间断开。

| 表达形式 | 适合的原文内容 | 画面 |
| --- | --- | --- |
| 属性记录 | 一个具体对象的字段和值 | 清楚的字段—值配对、小幅对象插画 |
| 实例矩阵 | 多条具有相同字段的实例 | 实际表头与行值，支持多句来源 |
| 对照 | 两种不同输出、条件或选择 | 相对分栏或成对行 |
| 关系 | 明确的主语、动作和对象 | 紧凑节点、带谓词的连线 |
| 时间线 | 原文明示年代与事件 | 顺序示意线，不暗示时间比例 |
| 数值算例 | 原文已给数量关系 | 大幅算式与正常字号的前提 |
| 注释 | 对象及若干实际要点 | 开放分栏或主项加侧项 |
| 结论 | 引入、一个观点或回顾 | 大标题及简短说明 |

`teaching_exhibits.py` 先选择形式与依据，再填此形式有效的内容，最后独立复核对象、字段、关系、条件和教学重点。不能把每种形式都填成同一组文字卡。

显式“字段值”列表可形成字面配对候选。分词器只帮助识别边界，不能决定教学对象；对象名仍须逐字属于依据、保留完整术语，并通过复核。无匹配、被拒稿和真实服务失败各自保留记录，服务失败不会冒充成功的演示结果。

数值算例不执行模型代码。四则运算通过有界 AST 核算；无效算式可从原文数值生成已经计算相等的候选，再由模型选择与原文含义相符的表达式。候选求解最多四项、十二种输入数值，不能处理任意代数、证明或动态函数。数值相等不等于教学关系正确，仍须核对原文的输入、运算、结果和前提。

关系候选拒绝疑问来源、并列名词作谓词、裸情态词、主宾倒置、把前一动作的宾语误当成后一动作主体，以及省去否定的正向箭头。程序的字面和语法检查是保守过滤，不是通用语义证明。

规划与审稿均收到本页标题和教学目标；一句话事实正确，但把实际环节与“插图建议”作比较，仍可能偏离教学重点。明确的“对象从来源移动到目的地”只重排已经复核的完整陈述，保留移动对象、起点、原词动作和终点，否定、条件化或不完整句子不进入这条画法。来源、目的地不是动作主体；并列名称只拆成平行项目，不补因果或时间箭头。已经在对象与短说明中完整显示的条件不在页尾重复。

`exhibit_svg.py` 实现开放构图、真实记录、矩阵与算式，插画仍为小幅辅助。正文至少24 pt，关系标签至少20 pt，拥挤时分页，不以小字或裁切掩盖内容。`rich_deck.py` 将同一页面同时用于 PPT 和 MP4；同一段录音在所有画面状态之间只用一次。

普通页面按来源句长度估算出现、聚焦及连线绘制时间，保持对象位置稳定；这不是语音强制对齐，也不是物理模拟。已有可计算数学场景、动画视窗与连续演示优先保留，不被插画或静态图替换。

## 本机复现

```powershell
.\.venv\Scripts\python -m pytest
# 需要本机保留的基线课程及音频；调用本机真实模型重新规划画面
.\.venv\Scripts\python scripts/verify_teaching_exhibits.py --case all
# 重新导出已保存的画面，不调用模型
.\.venv\Scripts\python scripts/verify_teaching_exhibits.py --case all --render-only
# 仓库包含的原创金融教材：从新 PDF 走完整真实模型流程
.\.venv\Scripts\python scripts/verify_fresh_finance_exhibits.py
```

机器学习私人教材只使用本机模型，讲稿、音频和生成物留在 Git 忽略的 `data/`。五份保留课程属于跨领域开发回归，不能当作未知教材的独立泛化证明。新增金融资料为原创输入，核对媒体和知识时应分别记录，不以视频导出成功替代语义验收。

### 用户截图中的具体问题

- 开篇的“西瓜—机器学习教材—习题”改为原口播中的引入问题；第二页用三条真实学习问题取代“主线、经验、规则”的散点。
- 箭头端点贴近实际节点；不再从空白处起线。连线词有完整展示区域，避免将短词单字换行。
- “假设样本”不再作为来源主体，疑问、状态定语和并列名词不能产生事实箭头。
- 一条记录明确配对属性与值。插画为小幅辅助，并绑定自身对象；三栏概念页不再附上悬空的西瓜。
- 恢复实际计数算例 `(3+1)×(2+1)×(2+1)+1=37`、带删除原因的 `8−1=7`、四行实例矩阵及既有连续曲线演示。
- PPT 和视频都有封面、结尾，完整视频每段原配音使用一次；来源、完整讲稿与技术记录保留在备注和网页中。

### 跨领域实测中发现和修复的问题

物理模型把“温度等条件保持不变的导体”误画为条件作用于导体的箭头；生物模型把地点“肺泡处”当主体，把完整术语“气体交换”拆成“气体→交换”。独立模型审稿曾放过这两类错误，因此加入通用词组、介词位置、状态定语与动作字段检查，并重新实际生成。介词位置按分词检查，避免把“等于”的末字误当成“于”。

生物第二页保留氧气“肺泡→血液”和二氧化碳“血液→肺泡”的两条扩散方向，回顾页展示三个实际环节；这些重排只使用已复核陈述，没有补作定量模拟。四种模板的字体与边界检查另由自动测试覆盖。

实际文件位于忽略目录 `data/visual-variety-repair/<case>/`：`lesson.pptx`、`lesson.mp4`、`lesson.json`、`acceptance.json`、`video-review-*.png`、`presentation-preview/manifest.json` 和模型调用 / 拒绝记录。总览中的截图来自最终 MP4 解码帧，不是模型草稿。

### 媒体检查的范围

五份课程检查完整视频解码、PPTX 包与 SVG、源 PCM 配音非空、完整配音时长、封面和结尾，以及普通片段终态与共享 PPT 预览的像素一致性。连续场景仍使用已有受检媒体，本轮没有把普通箭头出现当成数学或生理连续演示。PPT 预览由项目渲染，尚未进行 PowerPoint 应用放映；未完成逐字完整试听。

素材记录区分导演提出的候选 `director_asset_requests` 和真正显示在正文中的 `selected_assets`，后者按共享页面的实际插画区域统计。不能用候选数量宣称课件已经出现相同数量的图案。

机器学习已有记录、算式、矩阵、关系图、对照和连续场景；物理仍缺少丰富的真实电路画面，逻辑和图书课仍有文字性较强的页面。这轮不能宣称已经达到 NotebookLM 的整体画面表现、全书覆盖或任意教材泛化。媒体、局部画面忠实性和教学完整性分别记录。
