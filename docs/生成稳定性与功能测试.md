# 生成稳定性、图示与模板测试

更新：2026-10-12。

## 失败原因与恢复

本次实测发现两类失败：模型提供方、API 地址和模型名不匹配造成连接失败；模型已完成讲稿和配音后，固定概念框容纳不下文字，PPT 排版异常终止整个任务。

切换提供方现在使用独立的当前会话表单设置，并要求对应地址和模型。排版使用自动构图和连续页面；每页保留文字与条件，关系拆页保留端点和连接。导出失败保留本地配音；音频缓存按讲稿、实际音色、服务身份和文件校验值匹配，改变讲稿或音色、文件损坏时重新合成。缓存文件仍位于 Git 忽略的任务目录。

已完成课程和配音、在 88% 之后失败的普通任务可以使用保存课程恢复导出，避免重新调用语言模型：

```powershell
.\.venv\Scripts\python scripts/resume_job_export.py YOUR_JOB_ID
```

此命令保留原任务的课件内容和模板，使用本地语音并恢复网页任务状态。连续数学场景和外部语音使用网页的原任务重试流程。

## 真实模型与长视频压力测试

以下命令生成三份原创中文教材，使用本地 Ollama 为物理、金融、生物分别制作真实课程；另以合成测试音频编码 1280×720 的 30 分钟视频并完整解码。真实课程与合成负载分别记录，报告不把编码成功称为教学知识正确。

```powershell
.\.venv\Scripts\python scripts/verify_generation_matrix.py --real-local-model --long-seconds 1800
```

结果保存在忽略提交的 `data/generation-matrix/report.json` 与任务子目录。`--long-seconds` 可指定其他负载；30 分钟是本次验证时长，不是应用的最大视频时长。项目没有固定页数或目标时长上限；输入大小、模型上下文、推理能力和本机计算资源仍影响任务。

新致科技风的四套模板详见[课程导演与 PPT 模板](课程导演与PPT模板.md)。完整测试报告和具体生成文件仅存本地，不提交教材、密钥或缓存。

上述三份原创短教材用于验证跨领域的生成链路和不同图示布局，不能证明所有教材的知识正确性、数学动画质量或整本书覆盖率。
