# 四个学段的数学教材验证

日期：2026-10-08。本记录检查真实数学对象的 SVG 与连续动画，不把流程图、关系卡片、原页高亮或媒体编码通过当作数学推演通过。

## 材料与范围

选择八组真实教材选页，覆盖小学、初中、高中内容层级和大学。原文件哈希、作者、出版社链接、下载地址、许可和 PDF 物理页码见[来源清单](../examples/math-level-sources.json)。小学和初中采用 IM 的对应年级教材；高中采用 OpenStax Precalculus 内容，它也用于高校先修课程，[Virtual Virginia 的高中课程](https://virtualvirginia.org/course/pre-calculus/)选用 OpenStax。不是中国课标逐项对照，也不是四个学段的完整课程验收。

## 方法

- 本机 Ollama 0.40.0；小学、初中、高中使用 `qwen3.5:9b`，实际加载摘要 `c97eb11d70b1`，9.7B / Q4_K_M；大学极坐标尝试使用已安装的 `qwen2.5:7b`；Taylor 的两次 7B 提取失败后，用同一 9B 完成四个知识点尝试。7B 摘要 `845dbda0ea48`，7.6B / Q4_K_M。均为 8192 上下文、温度 0；9B 调用记录为 `think=false`，7B 的 `/show` 没有思考开关，实际调用记录 `thinking=null`（未发送控制字段）。`tags` 存在同名条目，实际模型以 `ps/show` 为准，不能凭别名推定权重。代码哈希、实际调用与错误写入本地记录。
- 仅向规划器提供选页提取的文字和统一数学演示偏好。知识点由模型提取，未预写分镜、坐标、函数参数或 SVG。来源清单的验收要求不作为具体场景提示输入。
- 每个提取知识点单独进入生产 `plan_visual_scenes(... geometry_only=True)` 路径，以保留局部失败。全部提取知识点均写入 `results.json`；未通过的知识点不通过换标题或删除来算整组成功。该工具隔离检查画面，不冒充整本书或完整课程顺序验收。
- SVG 进行 XML 解析和真实渲染；MP4 完整解码，检查 H.264/AAC、帧率、画幅、音轨、时长和非静音。每一步保存运动中和终点帧。本轮由 Codex 对照原页、实际数学对象、讲稿及画面做视觉与数学复核，技术成功只记为 `generated`；工具的 `human_review` 留为 pending，未代填真实使用者的审核。
- 独立核对来源页和数学条件、真实图形比例、对象身份、实际方向变化及计算与图形关系。抽帧不能当作完整配音试听或 PowerPoint 放映验收。

选页参与了调试，最终结果不是独立盲测。未使用原有线性变换专用模板，也未使用开发者编写的导数、概率等场景来证明教材自动生成效果。

## 已发现问题与修复

1. 旧表达选择把数学定义转成关系图或原页注释。新增 `geometry` 模式，明确要求数学对象；无法构造时失败，不以定性图示替代。
2. 旧 SVG 与 Manim 的横纵单位尺度不同，会破坏角度和长度比例。共用等单位视口，静态图和实际动画保持欧氏几何关系。
3. 小模型反复给出固定坐标却声明动态参数。规划前检查依赖，针对已有对象字段请求受限符号绑定；未声明变量、非法表达式和实际无运动仍拒绝。
4. 自由参数字典常输出空对象。步骤改用声明名称约束的 `parameter_changes` 列表，由程序绑定回执行参数。
5. 第一段“平角”动画说旋转射线，实际只伸长相反的线段，审稿仍批准。该旧成片验收失败；新增方向变化测量与运动口播检查，审稿读取实际测量，不只读参数名。新增参数曲线支持真实圆弧和闭合轨迹，不需要专题代码。
6. 强制三条知识点使短选页产生泛泛回顾和背景。允许一个有来源的知识点，并把教学范围传给提取阶段；数学模式向提取器传达排除人物历史背景的偏好，不预设教材主题；本机模型仍曾忽略该要求，不能宣称已经保证排除。
7. 数学公式在这些 PDF 中可见，却经文字提取消失。当前 OCR 只在少文字页触发，混合页仍有公式缺口。该项尚未解决；缺失的公式不能由常识猜补后当作引用。

8. 抽帧发现重合圆弧在视频里被圆的描边覆盖，SVG 却正常。Manim 的集合插入顺序导致图层不稳定，现按对象顺序给出稳定图层，显示/隐藏后仍保持同样次序。原创执行器探针在两个不同进程随机种子下均通过，运动中/末帧的橙色圆弧像素为 156/363，20.9 秒有声视频完整解码通过；它不是教材自动生成样本。

9. 高中抛物线页的页尾定义未进入模型：原标题词启发式误选“space”，每页六条摘录全部落在航天背景。数学对象模式现启用 `complete_sources`，有效摘录全部分批分析，不使用主题词的每页截断。相同选页/相同模型复测已经读到几何定义、顶点和通径；知识选择仍曾保留背景，几何规划仍有失败。这是输入链路修复的证据，不是成片成功。
10. 空参数变更引发重画同样对象；现区分步骤未改变参数与对象表达式错误，前者保留对象只修正步骤。同一无效分镜重复三次便失败，不重复五次。布局初态提前检查自由变量、保留参数名和函数定义域。
11. 线段沿同一直线坍缩再反向，旧方向测量可误当旋转；新增非共线中间方向检查，真实半周旋转通过，坍缩反向拒绝。不支持的 `${...}` 动态标签拒绝；角度单位与自然对数语义明确写入对象契约。
12. 自由数值计算不能保证数字对应画面。新增原文绑定的实际几何关系：模型选择来源编号、现有对象和受支持的关系，程序填写原句并测量点/线/曲线/圆/多边形。规划每步五个状态、渲染每帧执行；不接受模型代码、自定容差或恒等式 `0=0` 代替实际测量。
13. 旧抛物线视频中的动点不在曲线上、距离不相等，模型仍批准。保持其原始对象与步骤，同一 9B 模型绑定了 `on_function`，新程序检查在中间状态拒绝原视频（点纵坐标 2 与曲线值约 2.0155644 不同）。同一次绑定的另外两项把距离连接线误当距离目标，仍有对象角色错误；不能据此声称模型已能全面正确绑定关系。约束和对象改写会使旧场景批准失效，缓存重新核验。
14. 另一个顶点演示的焦点和准线在末步离开窗口，被遮罩隐藏。对含原文几何关系的场景增加可见点和标签锚点的窗口检查，规划采样与渲染每帧均执行；显式隐藏对象不触发此检查。曲线/直线可以在窗口边界裁切，未保证所有标签尺寸与全部画面构图。
15. 增加 `asin/acos/atan/atan2` 的受限数值与 TeX 转换，覆盖反三角函数定义域和象限；不能用单参数 `atan` 误替 `atan2` 后宣称已正确处理全部极坐标象限。

16. Taylor 提取反复给出契约外的 `definition/example`，旧反馈只有 `literal_error`。新增来自 Schema 的出错字段要求（枚举、类型、长度/格式及数值边界），不复制返回值、来源或密钥。模拟两种服务的修正与隐私测试通过；同一 7B 实测重试仍使用非法类型，因此只证明反馈具体化，不证明模型已遵守契约。

本机数学调用改用简单 JSON 解码，完整结构契约仍在提示中并由程序校验；不符合变量/字段约束的 JSON 仍拒绝。停滞时测得 GPU 使用约 7.6/8 GB 显存，个别生成约 0.08 token/s；换用已安装 7B 后预热仍慢，随后调用恢复输出。原生解码器、模型和资源负载没有做受控隔离，不能把恢复归因于某一个改动。只终止了本轮自己的停滞验证进程，未停止共享 Ollama 或用户应用。

### 已导出但错误的抛物线

- 定义段：焦点 `(0,2)`，准线 `y=-1.5`，所画曲线 `sqrt(x**2+4)` 是双曲线上支；动点始终 `y=2`，没有沿曲线移动。末步点到焦点为 1、到准线为 3.5，口播却说始终相等。52.03 秒 MP4 完整解码通过，数学复核不通过。
- 顶点段：焦点 `(0,p)`、准线 `y=-p` 的顶点应为原点，实际对象在 `(0,-p/2)`，对称轴还画成水平线。讲解声称准线不动，实际随 `p` 移动。末步 `p=4.5`，焦点和准线超出纵轴范围，顶点到两者距离为 6.75 和 2.25。50 秒 MP4 完整解码通过，SVG 与末帧均复核不通过。

以上原始对象没有被换成手写正确分镜。`generated=true` 保留其技术含义，另用 `codex_review.passed=false` 记录实际内容拒绝；不能把编码、模型批准或新执行器规则称为原教材生成成功。

### Agent、模型和输入限制

已确认并修复的 Agent/执行器问题包括来源截断、非等单位坐标、图层不稳定、空参数修复循环、假旋转检查、实际对象关系检查缺失及可见点越界。相同抛物线选页/9B模型在修复后读到原先遗漏的定义，且旧错误运动被新测量拒绝，是这些修复的直接证据。

剩余问题包括混合页公式未恢复、模型选择背景/重复主题、未声明变量、错误几何表达式、步骤不一致，以及模型审稿和关系绑定的误判。数学表达层当前只有受限二维原语和部分关系，还不能自动证明 Taylor 逼近、角和证明、面积分割守恒等全部推理。无法据此归因“只换大模型就解决”，也不能声称 Agent 限制全部消除。

## 复现

```powershell
.\.venv\Scripts\python -m scripts.verify_math_textbooks --manifest examples/math-level-sources.json --output data/math-levels/reproduce --download --render
```

可用 `--case primary-angles` 等选择一组，`--model` 指定已安装本机模型。默认逐组运行；缺文件时 `--download` 从记录的出版社地址下载并核对哈希，出版社更改文件后先重新审核材料。单独输入也可用 `--pdf 路径 --pages 5 --output 目录 --render`。

每组输出 `input.json`、`parsed-source.json`、`knowledge.json`、`model-calls.json`、`model-errors.json`、`knowledge-planning.json` 和 `results.json`。每个通过执行和模型审稿的知识点有 `lesson.json`、SVG/PNG、带系统配音的 MP4、计算记录、实际渲染几何和中间帧。生成失败也保留草稿及具体错误。

执行器复现（原创契约，不能计入教材效果）：

